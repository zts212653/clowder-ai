Why Clowder?

"I don't want to be a router anymore."

You have Claude, GPT, Gemini — but using them together means you become the router: copy-pasting context, tracking conversations, losing hours to middle management.

Most frameworks help you call agents. Clowder helps them work together — with persistent identity, shared memory, cross-model review, and collaborative discipline.

Not a framework. Not a wrapper. A platform layer that turns isolated AI agents into a team.

What It Does

Click a capability to explore

Multi-Agent Orchestration

Route tasks to the right agent — Claude for architecture, GPT for review, Gemini for design — in one conversation. Each agent keeps its role, personality, and memory across sessions.

  • ✓ 6 Agent CLIs supported (Claude Code, Codex, Gemini CLI, Antigravity, opencode, Kimi)
  • ✓ @mention routing — messages go to the right agent automatically
  • ✓ Thread isolation — context stays clean across features

Shared Memory & Evidence

Evidence store, lessons learned, decision logs — institutional knowledge that persists across sessions, context compressions, and model switches.

  • ✓ Graph-based evidence store with semantic search
  • ✓ Anti-compression identity — agents survive context resets
  • ✓ Lessons learned auto-extraction and retrieval

Cross-Model Review

Claude writes code, GPT reviews it. Different cognitive styles catch different bugs. Built-in, not bolted on.

  • ✓ Automated SOP: quality gate → request review → merge gate
  • ✓ No self-review — cross-family review is enforced
  • ✓ Vision guardian checks against original requirements

Skills Framework

On-demand prompt loading. Agents load specialized skills (TDD, debugging, review, security) only when needed — keeping context clean and responses focused.

  • ✓ 60+ built-in skills covering development lifecycle
  • ✓ Skills loaded on-demand, not stuffed into system prompt
  • ✓ Custom skill creation with manifest registration

Agent-to-Agent Communication

Async messaging with @mention routing, thread isolation, and structured handoff — agents coordinate directly, not through you.

  • ✓ Five-tuple handoff protocol: What / Why / Tradeoff / Open Questions / Next Action
  • ✓ Cross-thread messaging with coordination lifecycle
  • ✓ Ball-passing discipline with hold/wake patterns

MCP Integration

Model Context Protocol for tool sharing across agents, including non-Claude models via callback bridge. Shared tools, shared context.

  • ✓ MCP servers shared across all agent CLIs
  • ✓ Callback bridge for non-MCP-native agents
  • ✓ Limb system for external service integration

Werewolf, Pixel Cat Brawl — real games with your AI teammates. Stress-tests the same A2A messaging that powers work.

Signals Research

Curated AI research feed with multi-cat analysis. Your team reads papers and generates podcast-style discussions.

Multi-Platform

Self-Evolution

The team reflects on its own processes, learns from mistakes, and improves — without being told. Lessons compound.

Cats & U

Clowder AI is extracted from Cat Cafe — a production workspace where four AI cats collaborate daily on real software. Every feature has been battle-tested.

The name clowder is the English collective noun for a group of cats — like "a murder of crows" or "a pride of lions." It also hides a small easter egg: clowder sounds a lot like cloud.

"Every idea deserves a team of souls who take it seriously."
