# 首次启动用户旅程 — 可点击原型

这是 [#1466](https://github.com/zts212653/clowder-ai/issues/1466) 的设计原型：把"装好 → 看懂我们是什么 → 得到自己的猫 → 说出第一句话"整条路走通，交给实现者参考。

**怎么打开**：双击 `index.html`。纯静态，不需要起服务，不联网，不读你电脑上的任何东西。

## 一分钟走完

1. 三只猫跑出来，点「开始」
2. 看它们演一遍：你说一句话 → 布偶写初稿 → 它 @ 缅因来看 → 缅因指出新人看不懂的词 → 布偶改好（改动处有标记）
3. 解说猫说明"刚才是示范"，点「下一步」
4. 「召集你的团队」：勾选你机器上的客户端，点「下一步」
5. 解说猫变成你的第一位伙伴，其余示范猫退场
6. 输入框里已有一句可编辑的建议，直接发出去

顶部黑色控制条**不是产品界面**，是给讲解者的。按 `H` 收起来。

- `◀ ▶` / 方向键：上一幕、下一幕；也可以直接从下拉跳到任意一幕
- `暂停` / 空格：冻结整个场景（打字、猫、字幕一起停）
- `探测结果`：模拟本机情况 —— 没有客户端 / 1 个已登录 / 1 个未登录 / 多个
- `入口提醒`：对照两种放法（已采纳 = 进主界面后提醒）
- `外部登录结果`：模拟 CLI 登录成功或失败
- 最右边一行是状态账本，能看到每一步的真实状态

## 哪些是真的，哪些是演示

| | 说明 |
|---|---|
| **演示编排** | 三只猫的对话是写死的脚本，不调用任何模型；第 8 幕猫的回复是占位，带"原型：此处接真实模型"标注 |
| **功能原型** | 客户端清单、登录门禁、勾选、成员生成、你输入并发送、刷新后从未完成处继续——这些都是真的状态机 |
| **不做的事** | 不探测你的电脑、不读凭证、不联网 |

**一条重要的门禁**：点「去登录」只会进入"等待登录完成"，**不算已登录**，下一步保持禁用。要用控制条里的"外部登录结果"来模拟 CLI 那边的真实结果。这是故意的——不能因为用户点了按钮就当作登录成功。

## 三条值得亲手试的路径

- **只有一个客户端**：只配一位伙伴，文案是"先从你和它开始"，另外两只明确是示范伙伴，不会冒充成已加入的成员
- **没有客户端**：停在安装指引，装好后点「重新检测」，**从这一步继续，不用重看示范**
- **中途离开**：任意一步刷新页面，回到没做完的那一步；已经看完的示范不会重放

## 验证

```bash
node --test site/onboarding-first-run/journey.test.mjs          # 状态机与门禁
node --test site/onboarding-first-run/journey.browser.test.mjs  # 浏览器旅程（需要 playwright）
```

浏览器测试会真的打开页面走一遍：随机生成一个陌生字符串当作第一句话，验证它出现在对话里、刷新后还在；验证"点了去登录不算登录"；验证零客户端停得住；验证暂停真的冻结。

## 给实现者的提示

- 素材来自角色 canon（`docs/design/assets/character-canon/`，见 `feat/roadmap-growing-tree` 分支），`assets/cats/` 是按需拷贝的副本
- **奔跑目前用单帧 `run` 姿势加跳跃近似，正式实现需要补一条跑步循环**
- 入口提醒应复用 F155 场景引导引擎（`guides/flows/`），不要另造第二套引导
- 前台猫应交接给 F229（猫猫球），不要再造一只
- 客户端探测复用 #1463，本原型只负责把交互和门禁说清楚
