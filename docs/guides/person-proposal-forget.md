# 忘掉已处理的人物提议

如果一条人物提议已经拒绝或撤回，尚未记成人物，你可以把提议和当时的处理记录一起永久删除。

1. 打开侧栏的小信箱，进入「已处理的」。
2. 在「记人的记忆」中找到准确提议，展开后核对提出时间、提出的猫和原处；没有原卡的旧记录会明确说明。
3. 点「忘掉这条提议」，先核对关联提议的删除范围。
4. 勾选确认后，点「确认永久遗忘」。这不能撤销，完成后列表会刷新。

如果这组提议还有未处理的后继，或已有内容记成了人物，页面会拒绝删除。已存人物请到记忆页的「人物」中核对和处理。

如果页面还没确认结果，请使用保留的「再试一次」核对刚才那次操作。刷新后即使原提议已经消失，已处理页面仍会保留这次操作的恢复入口。

原聊天消息会保留。猫以后仍可能再次提议记住这个人。
