# 管理一条人物记忆或暂存线索

打开记忆 → 全部记忆 → 人物。页面需要当前主人的登录会话。

## 忘掉一条判断或共同经历

打开对应人物，在准确条目旁点击“忘掉这条内容”，核对说明后确认。来源读不到时仍可遗忘，
历史判断也可清理。操作擦除这一条的正文、来源关联和相关敏感内容，保留“这条内容已遗忘”标记。
不会删除原聊天或忘掉整个人。只想更正或标为不再成立时，继续用原来的编辑与“不再成立”按钮。

## 撤回或永久遗忘暂存条目

人物页下方的“暂存的人物线索”直接列出原暂存记录，包括待确认和已撤回记录；记录较多时可继续读取。
暂时读不到会明确提示，不把失败显示成没有记录。

- **撤回**：停止整理，清空暂存内容，保留一条已撤回状态记录。同一来源以后仍可能形成新提议。
- **永久遗忘**：彻底删除该暂存记录及其仍持有的队列、去重和绑定坐标。已撤回的记录壳也可清理。
- **已转成正式提议**：不能只删暂存这一部分。使用“前往原提议处理”打开小信箱中的准确提议；
  原提议无法定位时，页面会如实说明，不拼造链接或重新显示已清空的人名。

两个操作都不删除原始对话。永久遗忘不能撤销，也不承诺阻止同一来源在今后再次被提议记住。

## 取消、版本变化和结果未确认

确认前可取消，不会提交。版本已变化时先重读当前内容，再决定是否重新操作。
断网或服务暂时不可用时，页面会保留同一次已确认操作的恢复坐标；刷新后即使原行已消失，
仍可用“重试这次操作”核实原结果。
若页面显示“永久遗忘尚未完成”，可核对当前状态后选“继续永久遗忘”；它会接着完成原记录的清理。它继续使用原 requestId 和目标，不会改成另一次删除。
坐标按真实主人会话隔离；多个标签页的已确认操作各自保留、依次核实，不保存条目正文；浏览器不能保存恢复坐标时，不会提交操作。
