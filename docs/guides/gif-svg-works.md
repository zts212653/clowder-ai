# 查看和修改 GIF / SVG 作品

从聊天作品卡、作品目录或 Workspace 打开 GIF / SVG，可以查看原件，并围绕同一作品的具体版本提出修改意见。

## 帧定位与原件

打开 GIF 后，先暂停或用上一帧、下一帧停到要改的画面，再圈选或画笔标记。
意见会带上当前版本、帧号和时间；新版返回后可以对比，旧版仍可查看。
复制图片会复制当前显示帧；下载原件则保留 GIF 的完整动画。

SVG 可以放大看矢量细节，也可以圈选需要修改的位置。下载原件会保留 SVG 源码。
查看、标记和下载沿用原作品的访问权限；提出修改意见不等于已经采用新版。

## 支持的文件范围

GIF 原文件最多 10 MiB、最多 600 帧，累计解码像素最多 32,000,000；普通图片上传也适用这些预算。
超出预算会明确拒绝，不会把动画悄悄截成静态图保存。

SVG 原文件最多 2 MiB，支持静态图形子集。含脚本、事件处理、外部资源、DTD 或实体的文件会被拒绝，
动画、活动 HTML、外链字体和图片也不在支持范围内。合格原件保存原始字节，不通过删改源码来冒充原件。
