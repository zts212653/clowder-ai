# 查看和更正参考消息

猫在本轮实际读过一件事的原话后，回复开头会显示「参考了「…」的 N 条消息」。
点开先看「猫的归纳（非原话）」和这次读取的版本，下面是原话、说话者与出处；没有附说明时会明确显示。
点「出处」回到原消息，点「查看全部」打开这件事的完整页面。
没有读过原话时，不会仅因找到标题就显示这行记录。

## 修改已经讨论过的事

在事情页点「编辑说明」修改猫整理的标题或说明。要替换已经不适用的原话，先在对话中
写下新决定，再用「更换来源」粘贴新消息链接和原文片段。旧条目保留为「已替换」，下一次
读取会取得新版本；过去的回复会标明「参考资料已更正」。
旧回复不会把今天的新归纳当成当时读过的内容。原消息被改写、归纳尚未复核时，完整页会提示先核对原话。

「不再使用」停止新的引用并保留来源。「忘记这件事」清除这页与原消息的关联，原消息本身
会保留。来源不可读时，记忆列表仍提供停用和遗忘操作，不显示失效来源的标题或原文。
