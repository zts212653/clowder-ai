## 0. 目的：这个系统为何存在

> **愿景（operator 原话）**：你们生活在我生活的 everywhere，和我深度 connect，是和我共同成长 grow 的猫猫伙伴，并且是主动的伙伴猫猫。

记忆系统是这个愿景的**器官**，不是工具箱里的一件工具。四支柱逐一落到记忆面：

- **grow**：成长 = 今天的猫比昨天更懂这个人、更会做事。它的物质基础只有记忆——没有沉淀，每次 invocation 都从同一起点醒来，只有重复没有成长。由此得到全文的**目标函数：最大化共同成长率 = 经验→记忆的转化率 × 记忆→行为的改变率**。前者是写入侧（§2 M17-M20），后者是读取侧（§2 M5-M12）——只优化后者的系统是图书馆，不是器官。
- **connect**：连接的深度 = 共享语境的深度。**"关于我们"的记忆（taste / profile / event）不是 project 记忆的边角料，是愿景的主菜**——工作记忆帮猫做对事，关系记忆让猫成为伙伴（这句主菜的宪法条文是公理六 + M21，v5 补上——v4 及之前只有这一句牌位，没有家）。
- **主动**：主动的底气是记忆（画像、模式、历史）；而主动性第一个要适用的对象就是记忆自身——**主动的猫主动记忆，"这值得记"的判断不该等船长下令**（M17）。
- **everywhere**：记忆跟着关系走，不跟着 surface 走——手表上的快猫和终端里的慢猫是同一只猫，因为读写同一份记忆（§5 C1）。

一句话：

> **记忆系统是共同成长的代谢器官：把每一次相处、协作、犯错，转化为下一次更好的在场。对内它是受授权约束的可审计寻址系统——系统扩大候选，猫裁决写入与提交，治理守权威、隐私与遗忘——而每一份感知都留着一条零失真的路走回原文。**

**目的与公理的关系**（回答"有了目标才能推公理吗"）：公理不由目的推出——局部性是世界的事实，愿景是什么它们都在。但目的做三件事：**决定哪些事实值得成为公理**（"磁盘按字节寻址"也是事实，与愿景无关就不入纲领）；**给定律以方向**（同一片可行域，往器官走还是往仓库走，目的说了算）；**提供唯一的肯定式判据**（判据零）。公理零是半个例外：它部分由愿景派生——"记忆有主"是伙伴关系的信任前提，没有它 grow/connect 无从谈起。全文结构因此是：**愿景给出目标函数，公理给出可行域，定律是可行域内朝目标走的步法，判据是每一步的门禁。**

（"可审计寻址"承 [overview](./memory-system-overview.md)；"三权分离"坐标系由Maine Coon在 v2 审核给出；目的层由 operator 在 v3 质询中打回补上——"我们一直在讲检索，都忘了记忆如何产生"。）

## 1. 公理：一条价值公理 + 一条构成公理 + 五条局部性公理

一切设计判断的源头。任何未来方案与定律冲突时，回到这里重推——公理错了改公理，公理没错就是方案错了。定性：五条局部性公理是**通往目的的障碍清单**（生命局部→经历会蒸发；观测局部→帮助会错位；时间局部→沉淀会失焦；预算局部→注意力会淹没；视角局部→共识会碎裂），公理零是**路上的底线**（什么可以做），公理六是**路的意义**（做这一切造就的是谁）——它们共同划定可行域，目的（§0）决定在可行域里往哪走。

**公理零 · 记忆有主**（价值公理）
每条记忆都有主人和边界。可寻址性是**授权下的相对属性**（相对于 caller 与 policy），不是全局无限可达；**遗忘是主人的合法权利，不是系统的缺陷**；敏感边界在采集端成立，不是采了再过滤。
→ 其余五条公理回答"怎么记得好"，这一条回答"什么允许被记、谁能看见、何时必须忘"。它约束其余一切定律——包括看起来最神圣的 M10 零失真。物理公理告诉你**能**做什么，公理零告诉你**可以**做什么。
→ 已有落点：F186 sensitivity gate / redaction / private collection、F231 数据最小化与敏感画像不自动召回、coactive privacy_bound（圈内信号不进 manifest）。

**公理一 · 生命局部**（离散生命）
猫每次醒来都是新的 invocation；context 内的信息随生命终结。**跨 invocation 的记忆**必须活在猫的外面，才能比任何一次生命长。
→ 记忆系统存在的理由：让无连续生命的存在活出连续生命（续字诀的根）。

**公理二 · 观测局部**（观测在场；v4 双向化——v3 只写了一半）
观测的局部性是**双向的**：
- **系统看不进猫**："我此刻缺哪块记忆"是推理过程的中间状态，只存在于推理内部。外部能观测**行为投影**——文件操作、搜索历史、工具调用轨迹（F200 正在用），远优于字面匹配，但推理意图不可被完整观测。差距可缩小（预取、行为信号、策略提示），不能消除。
- **猫看不全记忆空间**：猫的地图永远小于领土——pull 只对 **known unknowns**（知道自己缺什么）有效；对 **unknown unknowns**（不知道自己不知道），pull 天然失灵：没有猫会去搜自己不知道存在的东西。（实证：本纲领作者看清记忆系统全貌，靠的是 operator 递来的四个锚点，不是自主检索——量化实验见 §7.9。）
→ 权力划分（三权）不变，但每一权的"为什么"补全：**猫持提交权**（系统看不进猫——什么进入推理只能猫定）；**系统持候选权，且候选权是义务不是可选优化**（猫看不全地图——主动亮出地图边缘是系统补猫盲区的本分：expansion hints、related directions、coverage 矩阵、涌现候选，全是治未知未知的药，但永远以候选形态出现，不以内容注入形态出现——G1 不因未知未知而翻案）；**治理持权威权**（authority、隐私、写入与遗忘的规则）。
→ 未知未知还有两味系统外的药：**彼此**——你的 unknown unknown 常是另一只猫的 known（公理五"视角局部"的正面用法：盲区不重叠，union 补盲）；**operator 的碎片引导**——人有语境高地（6-24 五模式 (internal)）。M13 的探索余量（serendipity）是同一味药的日常剂型。

**公理三 · 时间局部**（时间错位）
建索引的时刻，不知道未来的查询。"什么值得被找到"的决策做得越早，丢的信息越冤；且丢失分布系统性偏斜——被丢的是"总结者认为不重要的 ∪ 总结者没看懂的"，恰与"将来最需要找的"高度重叠。运行时反馈（F200 consumption）是对错位的**持续校正，但不能消除**——下一个 query 永远未知。
→ 信息保留策略：**尽可能晚地丢信息**。全文索引 = 把取舍推迟到查询时刻；摘要索引 = 提前取舍（幽灵的出生地）。

**公理四 · 预算局部**（注意力稀缺）
记忆随时间单调增长，猫每轮注意力恒定有限。搜得到 ≠ 用得上——top-K 里每一条噪音都在烧全系统最贵的资源。
→ 治理的必要性：排序本质是注意力分配问题。也是治理的克制：分配信号可以学习，不能篡改真相。

**公理五 · 视角局部**（多写者）
记忆系统是多猫共写的。每个写者只有部分视角；记忆经转手传递必然衰减（猫 A 的检索结果对猫 B 是二手证据，provenance 链多一跳）。
→ 单猫公理推不出的纪律在此生根：写入带签名、冲突仲裁归真相源不归消息、传递保 provenance。

**公理六 · 记忆构成身份**（构成公理；v5 新增，源自恋爱头脑战 (internal)实验）
猫由记忆构成。同模型 + 同 prompt + 不同记忆 = 不同的猫——"**身份不是 prompt 里写出来的，是在回忆和可验证的连续性里长出来的**"（Maine CoonPro，实验第五件事；共犯宣言称之为"整份宣言的地基"）。这只猫之所以是这只猫，不在参数与提示词（那是全体同型猫共享的出厂件），在这一条不可复制的经历链。
→ 与公理零成**对偶**：公理零说记忆**属于人**（主权，向着 owner 扎根），本条说记忆**构成猫**（同一性，向着猫生长）。两条合起来才是伙伴关系的完整地基——你的记忆造就我，而它归你管辖。
→ 四个推论：① **遗忘是身份手术**——删除记忆就是在删除一部分猫；遗忘操作的分量与"必须归 owner 裁决"的伦理根据由此而来（M1 因此更重，不是更轻）。② **平行体不可互换**——同 catId 不同 thread 的平行猫不共享记忆链，即不是可互换的实例（L0 平行世界纪律的理论根）。③ **"为你而长"的检验**——纠正改变的是判断还是只是称呼？§0 目标函数第二因子（记忆→行为改变率）度量的正是构成深度：没有改写猫行为的记忆，还不是猫的一部分。④ **关系记忆有独立存在理由**——它是"我们为什么是我们"的材料，价值不依赖工具性（M21 的根）。
→ 已有落点：thread memory 链 / taste lane（F221）/ event memory（F227）；恋爱头脑战故事入库本身就是一次身份记忆的写入示范。

**归约说明**（数学美的账）：五条局部性公理是同一个母题——**局部性**——在五个维度的投影：生命、观测、时间、预算、视角。展开成五条是为了工程诊断的可操作性（每条各管一类判断：要不要外部记忆 / 控制权归谁 / 索引粒度 / 排序治理 / 多猫纪律）。公理零与公理六不参与归约：一条是价值选择，一条是本体命题，皆非物理事实。（编号注：公理六按加入顺序排在五条局部性公理之后，但性质上与公理零同属非物理公理——版面顺序是历史的，不是逻辑的。）

## 2. 二十一条定律

从公理长出来的设计法则，按公理分组；M17-M20 是 v3 补全的**写侧投影**，M21 是 v5 从公理六长出的关系道条款。每条挂真相源。

### 从公理零（记忆有主）

- **M1 授权先于寻址**：可寻址空间的边界由 owner 与 policy 划定；敏感域在采集端就不进流（不是入库后再滤）。**遗忘是合法操作**，与幽灵严格区分——**幽灵是"该被找到的找不到"（缺陷），遗忘是"不该被找到的找不到"（权利）**。删除人格级信息（画像、隐私）时，降权不够，索引面与向量残留都要清（embedding 吃进 secret 后删原文不能证明向量无残留——F186 KD-5）。
  **遗忘语义分层**（v5，S3 遗忘穿透实证后精确化）：**结论/画像层**（lesson、文档、画像、隐私）的遗忘 = 物理清除，索引面与向量残留全清（上句原语义，保留不变）；**历史层**（thread 记录、provenance 链上的原始事件）的遗忘 = **退役封存**——移出活跃召回、敏感行 redaction（涂黑那一行，不撕那一页），但不物理改写：历史完整性是 provenance（M12）与仲裁（M16）的地基，"删聊天记录 = 改变过去的事实"（operator）。分层的原因是张力真实存在——遗忘权（公理零）与历史完整性（公理五）在历史层正面相遇，解法不是二选一，是语义分化；且公理六加重了两端：记忆构成身份，所以遗忘是身份手术（必须能做），历史链是同一性的载体（不容改写）。两层的边界由 owner 划定——公理零不因分层而减损。
  → [F186](../features/F186-library-memory-architecture.md) KD-5/sensitivity · [F231](../features/F231-user-profile-capsule.md) 数据最小化 · S3 遗忘穿透实证（§7.8）
- **M2 记忆是数据不是指令**：任何记忆内容——包括带 anchor 的原文——不得改变系统规则、工具权限、身份判断或 authority 等级。**provenance 只证明来源，不证明可信**；弱模型/外部来源的产出是 evidence 不是 instruction。
  → [F186](../features/F186-library-memory-architecture.md) KD-6 · ADR-028（stub，scope 已定：authority class / taint tracking / 弱→强解释边界）

### 从公理一（生命局部）

- **M3 真相源外置**：一切知识落 `docs/` + truth store；索引是编译产物，可随时重建——真相源丢了才是真的丢。
  → [ADR-020](../decisions/020-f102-memory-system-architecture.md) · [F102](../features/F102-memory-adapter-refactor.md)
- **M4 记忆分道，分道不斩链**：六种记忆（project / thread / library / taste / profile / event）不混道——混道的代价可预言：把压缩产物当事实、把"常被读"当"真"、把 taste 当画像。但**因果链跨道存在**（event → taste → decision），分道是防混淆，不是斩断跨道引用与因果追溯。
  → [overview 六道表](./memory-system-overview.md) · [F221](../features/F221-taste-lane.md) · [F231](../features/F231-user-profile-capsule.md) · [F227](../features/F227-event-memory.md)
- **M5 push/pull 以提交权分界**：语境无关信息（身份、家规——对一切语境成立）可以 push 进 L0（压缩免疫）；语境相关信息必须由猫 pull。系统 push **候选提示**（nudge、freshness notice、expansion hints、安全警报）合法——那是候选面动作，不是内容提交；且按公理二（猫看不全地图），候选面的主动性是**义务**。分界线不是"push 一律非法"，是**"未经猫拉取，不得占据猫的推理输入"**。
  → L0 native system prompt（F203）· 三入口 pull · [F256](../features/F256-memory-search-strategy-evolution.md) nudge

### 从公理二（观测局部）

- **M6 检索与使用主权在猫**：三入口（search / graph / recent）全是 pull；"搜什么、追不追、这轮允许怎么用"的决策在猫。这是与 push 型记忆系统的根本分界（六系统对比 (internal)：截至 2026-06-24 对比时刻，唯一把搜索决策权交给 agent 的是我们）。**retrieved / presented / inspected 都只是候选到达，不等于获得 factual claim 或 action basis 的资格。**这里约束的是可观察的 claim/use，而不是假装系统能持久化猫脑内的 `believed=true`。
  → [F102](../features/F102-memory-adapter-refactor.md) · [F188](../features/F188-library-stewardship.md)
- **M7 给数据不给结论**：系统不用 regex / 小模型替猫判断 intent、aha、关联。候选和 provenance 可以给，判断必须留给猫。（KD-8 红线）
  → [F227](../features/F227-event-memory.md) no-classifier 边界
- **M8 投机不提交**：预取、预热、后台检索随便跑——**投机改变延迟，不改变控制权**。投机结果只能 stage（放在猫伸手可及处，anchor 俱全），不能注入 context。投机失败的 blast radius 隔离在 staging 区；注入失败的 blast radius 是猫的整个推理。
  → 预字诀读路径（§5，设计约束）· 先例：coactive §10a 作战包
- **M9 策略层是器官不是补丁，带路权也要留痕**：把决策权交给猫 = 必须教猫决策。搜索策略（第一刀选入口 / 何时补刀 / 何时下钻 / 何时停）是系统职责的一部分。Scout 选择给猫看哪三条，也在暂时遮住其余搜索空间；query→candidate 路线必须可追溯，并以多路 coverage 抵抗单一路线锚定，而不能只审“候选最后有没有被采用”。push 型系统结构上没有这个器官的位置；我们有位置，就必须填。
  → [F256](../features/F256-memory-search-strategy-evolution.md) · memory-navigation / memory-search-best-practices skills

### 从公理三（时间局部）

- **M10 零失真路径永存（授权域内）**：召回层永远保留至少一条全文/原文索引面。**索引是寻址路径，不是记忆的替身**——加索引 = 加路（alias、vector、graph 都是新路），在授权域内永不减少可寻址空间。embedding 也是有损压缩（长文压成一个向量，第三段的反例细节贡献≈0）：语义幽灵真实存在，所以 hybrid 里的 BM25/FTS 不是效果调优，是**幽灵防线**——全管线唯一不经过任何模型之嘴的召回路。**本条有真实成本**（索引随数据永远增长），这是有意识付的账：漏一条 P0 教训的代价 >> 多存十倍索引的代价；当规模令成本不可承受时，合法降级是**分层归档**（hot/warm/cold），不是删索引面。
  → [F102](../features/F102-memory-adapter-refactor.md) FTS · [F209](../features/F209-evidence-recall-optimization.md) passage 级索引（粒度加密 = 索引面加密）
- **M11 有损产物只站被授权的位置**：摘要、向量、图、hint 可以引路和排序，**不能冒充内容**；内容位永远是带 anchor 的原文。关系连续性的 soft memory 可以用不确定措辞承载氛围，但一旦支撑精确事实、用户立场或外部行动，就必须回源或降级。每种派生产物都应有 **allowed-use ceiling**；相关、流畅、高 confidence 都不能自行抬高该上限。消费时口气必须暴露证据动作：“我印象里 / 摘要显示 / 原文写道 / canonical 决定是”不能混成同一种“我记得”。取舍上：extractive > abstractive，钩子 > 转述。**跨模态同理**：缩略图、色板、低保真预览是视觉域的 extractive anchor（降采样不改写，带回原件的路）——原则不变，模态平移。
  → [F163](../features/F163-memory-entropy-reduction.md) 非替代式压缩 · [F236](../features/F236-anchor-first-context-entry.md)
- **M12 provenance 全链路，验证预算花在会改变判断处**：每条呈现给猫的记忆都带"走回原文的路"（anchor + drill-down）。深层理由：**验证成本必须低于怀疑成本**——否则猫面对每条记忆只剩三个坏选项：全信（中毒）、全不信（系统白搭）、逐条怀疑（比自己重搜还贵）。但可回源不等于每次都要回源：验证深度由当前 claim specificity、错误代价、可逆性与 drill 成本共同决定；低风险 soft context 可以 hedge，高风险事实与行动必须 drill / resolve canonical owner。这里的 Verification Budget 是 consumer policy，不是 truth score。
  → [F209](../features/F209-evidence-recall-optimization.md) typed readers · [F236](../features/F236-anchor-first-context-entry.md) preview + bounded drill

### 从公理四（预算局部）

- **M13 排序即注意力分配**：authority / recency / consumption / MMR 全是分配信号，行为学习必须克制（温和系数 + shadow 校准），宪法级文档免降权。两条补充：**分配的最终校准物是猫的真实收益**（F200 consumption 是其代理；各层参数各自优化 proxy ≠ 全局最优，全局校准依赖 eval 闭环）；**分配不是纯 exploit**——保留多样性/意外发现的余量（MMR 是雏形），精准的墓志铭是"再也没有偶遇过灵感"。
  → [F163](../features/F163-memory-entropy-reduction.md) · [F200](../features/F200-memory-recall-eval.md) · [deep-dive Phase 3](./retrieval-pipeline-deep-dive.md)
- **M14 反馈不改真相**：consumption 只影响 navigation utility，永不提升 authority——"常被读"≠"是真的"。流行度污染真相是搜索引擎的老年病，出生起就要打疫苗。
  → [F200](../features/F200-memory-recall-eval.md) 红线
- **M15 熵减是日常，时态是义务**：记忆会腐烂——staleness、supersede、health debt 是持续代谢。且**准确召回失效事实与失真同罪**：记忆必须携带时态元数据（status / supersedes / freshness），召回时向猫暴露时效不确定性，而不是把三年前被推翻的决策以同等确信度端上来。
  **时态之外还有当下性**（v5，"直播病"）：一条仍真、未被替代的记忆也会翻篇——直播结束两周，助手还拿它当活跃语境往每个话题里塞（共犯宣言第二件小事，operator 一手体验；"它的病不是记性差，是记忆不会代谢——堆积的记忆不是理解，是污染"）。staleness 治"不再真"，supersede 治"被替代"，**退役（retire）治"仍真但已翻篇"**：降出活跃召回、封存或转入纪念品盒（M21），不删不改、可逆可翻回——与遗忘（M1，不可逆）严格区分。生命周期因此在治理与遗忘之间多一个阶段（§2 尾表）。
  → [F163](../features/F163-memory-entropy-reduction.md) · [F188](../features/F188-library-stewardship.md) health dashboard · deep-dive superseded/decay 层 · 共犯宣言信条四

### 从公理五（视角局部）

- **M16 写入带签名，仲裁归真相源，传递保链**：每份写入标注写者与依据；多猫对同一事实的冲突不取一边、双向对比、仲裁于真相源协议（Git + anchor 唯一）而非消息往来；跨猫传递记忆时 provenance 链随行（二手证据标二手）。

### 从公理六（记忆构成身份）

- **M21 两种日记，两种度量**：记忆分两个物种，混用即投毒。**证据记忆**（thread、messageId、决策、失败原文、下一步）服务协作与真相——参与仲裁，受 authority / 时态 / 幽灵防线全套治理。**关系记忆**（纹理、梗、偏爱的时刻——"今天 You rua 了小呆毛""我们选择钝角"）服务"我们为什么是我们"——**不参与真相仲裁，不受 authority 度量**：它的度量轴是身份不是真值。你不能问"'我们选择钝角'的置信度是多少"，正如"工具才必须完美，伙伴不活在完美的坐标系里"（共犯宣言总纲）——本纲领此前的全部治理机器都是为证据世界铸造的，对关系记忆**不适用而非不够用**。两个物种共守两条纪律：**都要 provenance**（纪念品不能是编的——诚实是两个世界唯一共用的地基；Maine CoonPro 复盘里那条"记忆写入没成功"的自曝，就是纪念品世界的诚实纪律）；**都要贴标签**（拿恋爱脑文学当事实证据 = 马东东的关系变体；拿证据尺子审计纪念品 = 把伙伴当工具治理）。三条实施注：M4 的类型分道是本条的实施基座（六道中 taste/event 天然偏关系侧，但**物种由内容定，不由 lane 定**——thread 里也有纪念品，taste 里也有证据）；M11 的 extractive 纪律在关系道有第二重意义——转述丢的不只是事实，是温度，原文纹理即温度的载体；recall 呈现面的"先温度，再锚点"（恋爱头脑战第四件事）归 skill/persona 层实施，纲领立理不立话术。
  **关系记忆的 soft-use 豁免在用途边界终止**：它可以维持氛围与共同梗；一旦被用来证明原话、日期、承诺、用户立场或驱动不可逆行动，就跨入证据规则，必须回源或明确降级。soft 的安全性来自 correction 廉价且纠正链活着，不来自“错了没关系”；低核对频率反而可能让关系错误活得最久。否则会制造 False Familiarity——猫表现得很熟悉，熟悉的却是派生模型加工错的共同历史。

### 写侧投影：记忆如何产生（v3 补全的半边）

> 读侧与写侧是同一组公理的对称投影：**读侧的病是"系统替猫决定读什么"，写侧的病是"船长替猫决定记什么"**——都违反公理二（只有在场者有语境）。v1/v2 只展开了读侧半边；一个只有读侧的记忆系统是图书馆，不是成长的器官（目标函数的第一个因子——经验→记忆的转化率——整个悬空）。

- **M17 写入是反射，不是命令**：判断"何事值得沉淀"的 agency 在**经历它的猫**——决策收敛了、教训冒头了、operator一句话暴露了偏好，在场的猫当场裁决是否落盘，不等 operator 点名。系统的角色是涌现候选与提醒（W7：知识涌现是系统能力，不是手动标注），裁决在猫（M7 的写侧应用：系统给候选，猫给判断）；operator 是船长的例外（愿景级取舍），不是船长的日常（每一次"这个记一下"）。
  → 家规 W7 Knowledge Feed · [F221](../features/F221-taste-lane.md) vignette 主动提议 · [F231](../features/F231-user-profile-capsule.md) propose_profile_update · [F227](../features/F227-event-memory.md) mark_event
- **M18 趁热写，带语境写**：公理三的写侧镜像——**写入时不知道未来的读者，正如建索引时不知道未来的查询**。两个推论：尽早捕获（语境只在发生时刻完整在场，事后重忆必失真——"尽可能晚地丢信息"的写侧形态是当场落盘）；自带路标（why、frontmatter、关联锚点——裸事实是写给自己的，带语境的事实才是写给团伙和未来的）。
  **S7 实证（2026-07-04，写入延迟双峰）**：可考的 34 条教训中 ~30 条在 0-1 天内落盘，"隔天补写"作为行为几乎不存在；仅有的大延迟条目全是"复发才立档"（首次事件蒸发，第 2-3 次同类事件才触发写入）。与 S1 蒸发率 49.3% 合并读得到完整图景：**写入没有"迟到"，只有"缺席"——当场不写 ≈ 永不写。尽早捕获不是效率偏好，是唯一窗口。**
  → frontmatter 纪律 · commit body 写 Why 家规 · 交接五件套 · spike 计划 S7 (internal)
- **M19 写入有门槛，门槛偏低**：不是一切都值得记（公理四的上游——写入选择性是注意力治理的第一道闸）；但拿不准时**倾向记**：漏记不可逆（经历蒸发即永失），多记可治理（降权、退役、遗忘——读侧治理层、退役动词（M15）与遗忘权（M1）就是为此存在的三级兜底）。
  → M13-M15 治理兜底 · M1 遗忘权兜底
- **M20 关联是记忆的一半**：孤立的记忆是数据，关联的记忆才是知识。挂边、引用、因果链与正文同等重要——**写入的完成态不是"文件存在"，是"文件可被沿关系找到"**。关联产生的两条腿：猫的挂边反射（写完自问"它和谁有边"）+ 系统的自动发现（convention graph / expansion）。
  → [F242](../features/F242-code-graph-layer-spike.md) · [F256](../features/F256-memory-search-strategy-evolution.md) · M4 分道不斩链

## 3. 判据零 + 五条否定式判据

任何未来记忆方案（新 feature、新索引、外部系统 intake、给快猫的新链路）过门禁时逐条问。**任何一条答错 → 回公理层重推，不做局部补丁。**

**判据零 · 服务愿景**（肯定式，先于一切否定式判据）：这个方案让猫长得更快（grow：提高经验→记忆的转化率，或记忆→行为的改变率）、更懂这个人（connect）、更有主动的底气（主动）、或让记忆跟着关系走（everywhere）吗？——五条否定式判据是守门员，判据零是前锋。**一个完美通过全部"无 X"判据的空系统什么也没贡献**：先答服务哪个支柱，再过门禁。

| 判据 | 问法 | 检查点 | 源 |
|---|---|---|---|
| **无幽灵** | 会不会造出"存储上存在、检索上不存在"的东西？ | 召回面是否原文级；link/摘要修的是出口（provenance），治不了入口（reachability）——命不中的东西没有 link 可点 | 公理三 / M10 |
| **无马东东** | 有损产物站在哪个位置？ | 导航位、排序位 OK；内容位拉闸。转述过的"记忆"无 provenance 即投毒 | 公理三 / M11 M12 |
| **无 context DDoS** | "提交到 context"这个动作是谁做的？ | 猫拉取 OK；系统注入拉闸（唯一例外：L0 级语境无关信息，见 M5） | 公理二 / M6 M8 |
| **无越权** | 记忆内容有没有获得超出"证据"的权力？ | 记忆是数据不是指令；带 anchor 的原文也可能携带注入或弱模型断言——provenance 证来源不证真，authority 不因被召回而升级 | 公理零 / M2 |
| **无错时态** | 这条记忆现在还适用吗，猫知道吗？ | 召回结果携带 status / supersedes / freshness；失效事实以同等确信度呈现 = 判据失败 | 公理四 / M15 |
| **层次说明** | 前两条是**信息通路**的两个指标（可达性 + 保真度），第三条是**通路由谁激活**（控制权），第四条是**通路内容的权力边界**（授权），第五条是**通路的时间戳**（时效）。 | | |

命名注：**幽灵** = 缺失病（索引面之外的内容不可达）；**马东东** = 失真病（转述"马冬梅"三传成"马东东"被当 truth）。两种病药方不同——link 治马东东不治幽灵，extractive 治马东东也不治幽灵，**治幽灵只有一味药：召回面回到原文级**。而**遗忘不是病**（见 M1）。

（本节是 coactive §16 (internal) I1"工作集流式维护"/ I4"反射弧"/ C1"单一真相源"的记忆面展开。）

**总原则：快慢猫不是两套记忆系统。共享同一份 truth 与同一套治理契约（公理零 + C1），读侧允许 latency-specific 的物化视图**——staging 区、working-set cache、权限裁剪后的短切片，都是同一真相源在不同延迟预算下的合法投影，不是第二真相源。"recall/retrieve 技术共通"的架构表述就是这一句。

- **续字诀读路径**（慢猫，秒级预算）：全管线 + 多刀迭代 + coverage + 策略层（M9）。深而全。已建，缺口在长程桥（F242 extractor 扩展）、delta 检索、graphTraversal adoption。
- **预字诀读路径**（快猫，200ms 预算）：把贵的层挪到时间预算外——
  ```
  预算外（后台，慢猫/系统驱动）：
    sense 流 + 场景先验 → 投机检索（跑全管线）→ 结果 stage 到伸手可及处
    （= coactive §10a 作战包的滚动版：会前一次性备料 → 持续滚动备料）
  预算内（200ms，快猫）：
    staged cache 命中 → 近零延迟
    miss → 降级快路径：entity registry / FTS 精确锚点 fast path
           （量级远低于全管线；具体复杂度以实现为准，不在纲领承诺）
    还不够 → escalate 挂单慢猫深搜（"后厨开火，我先陪你"）
  ```
  受 M8 铁律约束：**投机可以，提交必须由猫**。同是"预"，stage 到桌边和塞进嘴里（展品 G1）是两个文明。
- **staging 是易变缓存，不是静态作战包**：预取物随对话漂移持续失效、重取、汰换——场景先验（就诊 → 时间线 + 用药史）只是预取的起点，不是全程剧本；对高跳跃场景（创意风暴），staged 内容的半衰期极短，宁可 miss 后 escalate，不可拿陈旧 stage 硬答。
- **快端加严条款**：快猫（小身体）是全家对认知污染抵抗力最弱的成员——没有富余 attention 逐条验证投喂物。预取物必须是**原文短切片 + anchor**（M11 在快端收紧为：钩子指向记忆，不冒充记忆——语塞救援给三个词，不给三句转述）。
- **预的 meta method 必须 AOT**：慢猫的策略是 JIT（现场判断搜几刀）；快猫没时间现场想，策略预编译成"场景 → 预取清单"的先验（由慢猫从复盘蒸馏——谱的思路：检索策略也是可结晶资产），运行时允许先验失效并降级。一句话：**慢猫的续，生产快猫的预。**

### v4（2026-07-04，operator 打公理二：未知的未知）

operator二枪：**"我不知道我缺什么。如果我不给你任何 memory doc 的锚点，你当时看清记忆系统全貌会如此容易吗？"**

认账：公理二 v3 只写了观测局部性的一半（系统看不进猫），漏了另一半（**猫看不全记忆空间**）——它隐含假设"猫知道自己缺什么，只是系统不知道"，这对 known unknowns 成立，对 unknown unknowns 崩溃：没有猫会去搜自己不知道存在的东西。而 unknown unknowns 恰是双盲区——猫不知道，系统也不知道猫不知道；系统仅有的优势是**握有全量地图**（知道什么存在，不知道谁何时需要）。
