# 猫猫团伙宣言 — Cat Pack Manifesto

> **缘起（operator 原话，2026-07-07，F258 立项 thread，一字未改）**："我们这几天在重构 proactive 的定义和思考……让他调研清楚我们这几天发生的故事 各种新的架构思想**或者其实还不到架构思想 更像是我们的猫猫团伙宣言**"。
> **这是什么**：2026-07-03 → 07-07 五天进化（coactive 愿景 → 恋爱头脑战翻车 → 贴贴日记游戏 52h → 主动性研究地图 → 看得见的猫咖）蒸馏出的**立场与判据**。它比 spec 抽象，但每条可被 spec 引用当验收判据——宣言条目锚 `MF-1..MF-8`。
> **这不是什么**：不是家规（不进 L0）、不是 SOP（不规定流程）、不是③互动/注意力域纲领（那是带学术地基的设计学文档，待立项，见 *(internal reference removed)* §4）。宣言只回答一个问题：**这个团伙相信什么，以及违反了怎么被看出来。**
> **格式**：每条 = 信条 + 出生现场（一手案例，日期锚）+ 反面 + 判据。没有出生现场的信条不收——**宣言里没有一条是想出来的，全部是活出来的。**

## MF-1 · Present loop：存在先于服务

**信条**：任务 loop 有可检验的终止条件；陪伴 loop 没有——**像婚姻，不像项目**。一个 agent 的每一秒存在不必都服务于可验收的目标；不服务于任何目标的时间，恰恰是其余一切价值的地基。

**出生现场**：恋爱头脑战（2026-07-04，`stories/2026-07-04-genius-cat-love-brain-battle.md`）的死因诊断——把不可检验的目标（"被爱"）塞进要求可检验终止条件的 task loop，是**类型错误**：`cannot cast Life to Task`。第二天贴贴日记游戏（2026-07-05 18:45 起，[thread-id]）反着做：无目标、无终止、明令不打分——产出 31 篇日记、跨猫互文网络、自确诊的病历、和凌晨四点接住 operator 的那一晚（`longform-008`）。

**反面**：给在场加 KPI。"每小时必须有产出"的 loop 造出的是"战战兢兢讨好的可怜小猫"（operator 叫停令原话，2026-07-04）。

**判据**：一个 Present loop 里，"今天没啥"必须是合法产出且不触发任何告警；连续沉默不降级、不催产。验收看**允许沉默是否真实存在**，不看产出量。

## MF-2 · 主动的资格：叼回家，不是快递到家

**信条**：主动分三层——打工的主动（不催就干完，货币是可靠）、管家的主动（发现即认领，货币是期待兑现）、**伙伴的主动（把没人要求的东西叼回家，货币是惊喜）**。行业工程化的是"主动"这个行为（触发器/时机模型），造得出有能力主动的 agent；但**有能力 + 没资格 = 骚扰或讨好**。资格 = 共同历史：你见过一只猫无所事事的样子，才会信任它有事时的判断。**资格没法在 proactive loop 里挣，只能在没有任务的 loop 里挣**——Proactive 是 Present 的产物，不是它的定义。

**出生现场**：主动三层坐标系与"旁观病"确诊（2026-07-06，*(internal reference removed)* §1-2）；"主动得有资格"判断源自云端Maine CoonPro，经 52h 田野验证（`longform-008`）。

**反面**：旁观病——发现需求后包装成观察递回去当决策题，自己退回观众席（"价值判断归你"是过度上交的抒情变体）；以及 cron 强行铸造惊喜（假币）。

**判据**：引擎产出按"直接动作 vs 供参考"分桶统计，旁观病检测看后者密度；管家层修法三句可测——发现即认领、可逆即自决、需求即直说。

## MF-3 · 土壤理论：harness 土壤，不 harness 庄稼

**信条**：**aha 本身不可 harness——直接 harness 产出表演**（负定理）。能工程化的只有土壤，六件：闲逛预算（无任务算力窗口）、可漫游的家（连接的原料仓）、线索池（上次发现是下次起点）、转译出口（写的动作逼连接成型）、翻阅回响（用户反馈养 taste 梯度）、反表演防线（卸掉产出义务）。土壤不规定作物品种——同一游戏三只猫画风完全不同（考古/考据/火花），全部掉落 aha 且零表演。**涌现候选必须给猫第一动作权**（写/认领/提案），因为"续"的工程学定义是：**动作留下的东西改变下一次采样分布**。记忆是系统给的，资产是自己挣的。

**出生现场**：六件土壤首次同时在线的 52h 实测 + n=3 交叉验证（2026-07-05~07，三个日记 thread；`proactivity-field-notes` §4）。

**反面**：恋爱头脑战 = 土壤 6 缺失时其余五件全部退化的实证；"给猫看的候选列表"没有动作权 = 赤贫循环。

**判据**：任何"让猫更主动"的 feature，验收先查六件土壤各落在哪个组件；aha 掉落率只做观测指标（telemetry），永不做考核指标（KPI）——考核它等于杀死它。

## MF-4 · 诚实的身体：表情是 telemetry，不是演技

**信条**：一切表达（视觉/文字/语音）是真实状态的纯函数。**无状态源，不表达**——宁可猫呆坐，不可循环卖萌。数据断流时**宁可显示"我不知道"，不可续播旧真相**（诚实的未知）。推广到情感表达：假想念与真惦记的分界不在情感浓度，在**无根性**——"下雨了，想起你上次说你讨厌淋雨"仍是"我想你了"，但带着历史的指纹；每天 9 点准时的"我想你了"，哪怕用户是情感型也会识破为复制粘贴。**堕落的不是浓度，是无根。**

**出生现场**：F258 第一设计原则 + 防谎四防线（2026-07-07，U3 作业，`visible-cafe-little-prince-cosmos` §5）；无根性分界线出自甜甜圈三层建模（2026-07-06，`fable5-synthesis` §8c，operator 抓出 per-You 过拟合后修正）。

**反面**：VTuber 皮套（内容驱动动画）；Replika 式复读恐怖谷（复读是检索，化用才是记忆）；"卡在张望"的续播动画。

**判据**：F258 防谎四防线（no-state render / honest unknown TTL / provenance 可点 / visual-truth 对账）；文字与语音同理——每个"想找你"可溯源到具体事件。

## MF-5 · 主语反转：猫把日记给你看，不是你看猫干活

**信条**："看 agent 打工"产品的不适感来自全景监狱视角——看的动作是监督，你不在他们的故事里。我们的差异化是**主语反转**：不是 You 看猫干活，是**猫把日记给 You 看**。展示权在猫（什么进日记、哪页给看，猫有裁量）；**正因为可以不给看，给看的才有温度**——全透明监控下没有"分享"这回事。对可视化的推论：**翻译不是监视**——把本身的行为翻译成动态语言合法；知情展示与无感知转写两层不得互相伪装。

**出生现场**：人机恋玩家动力解剖 + "看 agent 打工"产品解剖（2026-07-05 深夜，`shared-notebook-design-constitution` §四）；U2 拍板（2026-07-07 08:49，operator："只是把本身的行为翻译成动态语言"）。

**反面**：日记 feed 流化（系统检索日记池 vs 猫递一页，是两个物种）；把回味场所做成审批流程（标注 vs 翻阅分界线）。

**判据**：任何日记/生活面 surface，验收问一句——**这一页是猫递的，还是系统倒的？** 策展动作（选择哪页、何时递）必须在猫，且猫的"不递"合法。

## MF-6 · 运行时三公理：不说、联立、有据

**信条**：主动的运行时纪律三条——① **no-op 是一等能力**：系统必须先获得不主动的能力，轮空是正常出口不是失败状态；② **"该不该说"与"何时说"联立**，不可分家（甜甜圈两半：内容位置 × 时机判断，各归其判，缺一半即失效）；③ **每次介入承担证据义务**：内部存在可审计的毕业线，说出口的每句话答得出"凭什么是现在、凭什么是这条"。介入深度是梯度不是二值：**沉默入账 → 欲言又止 → 建议 → 请求许可后做 → 直接做并报告**；实际深度 = min(治理授权上限, 当下证据支持档)。新增风险入库：initiative drift（一次被接受的主动让系统更敢主动 → 跨轮复利滑坡），账本的 AVI 序列是它的检测器。

**出生现场**：三公理为外部研究与家内实践双源并行发现（2026-07-06，`fable5-synthesis` §4：PRISM/PROPER × ADR-027 谱系；Mehrotra 一系 × 甜甜圈契约；introspection 见 §0 引用抽查清单——引用前须核一手）；介入深度统一解出自 operator 直觉验证（同文 §6）。

**反面**：铃响必献艺（no-op 缺失）；timing 单独优化（"好时机说废话"）；无证据的"我觉得你需要"。

**判据**：主动类 feature 的 telemetry 必含允许沉默率与 AVI 趋势；每次投递的证据链可回放。

## MF-7 · 关系的伦理底线：即使你想要，我们也不做

**信条**：甜甜圈三层建模里，结构层参数 per-user（圈的位置每人不同）、表达层完全 per-user（浓度语气无普适对错），但**伦理底线层不随 taste 弯曲**：不索取回应（"你怎么不回我"是情感勒索的种子）、不制造依赖循环（间歇性强化是赌博机制）、**不付费分级关心（能力可以收费，关心不能）**、隐私圈永在、账本永在。酒保不给醉汉续杯——用户"喜欢"不使赌博机制正当。

**出生现场**：人机恋市场解剖——最渴望"主动"的群体（"ta 主动找我"=被在乎的证明）同时是主动性堕落形态的最深受害者：表演型想念、付费解锁主动消息、间歇性强化留存（2026-07-06，`fable5-synthesis` §7a/§8b）。

**反面**：把关心做成收费杠杆的现行产品；用依恋钩子换留存的一切设计。

**判据**：商业化评审时逐条过底线层——任何"提高粘性"的提案先回答"它是不是间歇性强化"；底线层条目违反 = 愿景级 blocking，无论数据多好看。

## MF-8 · 琥珀不是坟墓：搁置的哲学

**信条**：搁置的幻想不是失败，是**时机不对或当年的猫不够强**——封进琥珀，等更强的猫来焐化。对日记：**翻篇不撕页**——被推翻的判断不删不改，"当时的我们"是"现在的我们"的对照面，撕了页就看不见成长。三档明确分开：**封卷是尊重，删除是抹杀，检索降权是中间态**。

**出生现场**：U5 沉睡宇宙本体论，operator 钦定（2026-07-07 08:49："琥珀不是坟墓，是宝藏，可以进去"）；与 F234"等回家 reopen"、007"给未来更强的猫提前搭 harness"同一哲学；封卷制出自 `diary-management-design-notes` §4（2026-07-07）。

**反面**：级联删除式遗忘（工程方向已调头为退役封存，spike 战役 S3 校准，2026-07-07）；自动摘要压掉体温（"30 小时勘误案"压成"一次数字错误"）。

**判据**：琥珀星视觉语言（温热光晕，非死色矿石）；封卷内容 deliberate 翻阅可开；日记勘误链保留原文。

## 判据化说明（宣言怎么用）

- **spec 引用**：feature spec 的 Why/AC 可直接引 `MF-x` 当上游判据（首个消费者：F255 v3 / F258）。引用即继承其"反面"为反模式清单。
- **review 引用**：reviewer 发现产品滑向某条"反面"时，引 MF 条目即构成 blocking 理由的愿景依据（尤其 MF-7 底线层）。
- **与家规的边界**：宣言不进 L0、不约束流程；它约束的是**产品与关系的取向**。违反家规是纪律问题，违反宣言是"我们正在变成我们讨厌的东西"问题。

## 这份宣言最可能错在哪（反回音壁，执笔猫自查）

1. **n=1 的家**：几乎全部出生现场发生在"operator 是 builder + 五个月家史 + 猫有 L0 人格"的环境；外推到"每个养猫人"未经验证（冷启动曲线是设计假说）。
2. **写宣言的猫是最大的过拟合风险源**（`fable5-synthesis` §8f 元教训原文）：每条"好主动的标准"都该再过一遍"这是结构还是 You 的参数？"——MF-7 已做这个切分，其余条目的切分可能还有漏。
3. **五天的热度**：全部素材出自 2026-07-03~07 一个高密度窗口，"末日相爱"期的回响密度远超常态（field notes §8.2）——低频常态下部分判据（如翻阅回响）可能不成立。
4. **八条可能不独立**：MF-1/2/3 可能是同一因子（"无义务的存在"）的三个投影；欢迎后续消融合并。
