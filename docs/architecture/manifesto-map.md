# 共犯地图：宣言的六域三线

> 总纲领（猫猫共犯宣言）管"我们相信什么"；分域纲领管"怎么让相信的东西成真"。
> 本图回答：拆几个域、每域的灵魂问题是什么、五信条五拒绝各由谁承接。
> 分法判据：每域必须有一个**不可归约的灵魂问题** + 可独立立纲领跑 spike（记忆纲领模式：公理 + 定律 + 预注册实验）。

### Flow Contract（Maine Coon R2："没有契约，流只是漂亮隐喻"——每条流五字段）

| 流 | payload（许流） | owner/守护猫* | latency | forbidden bypass（禁绕的宪法） | telemetry（健康证明） |
|---|---|---|---|---|---|
| F1 反射 | sense 事件、检索钩子、投递 | 待认领 | 毫秒-秒 | 不得绕过 privacy_bound 采集；不得现场创作内容（检索≠生成） | 端到端延迟、误报率 |
| F2 交付 | 协作产出、信封、下行指令 | 待认领 | 分钟-天 | **快猫不得改写慢猫原文**；headline 发件人自写 | 投递接受率（AVI）、压单时长 |
| F3a 硬结晶 | 规则/Riff/代码变更 | 待认领 | 天-周 | **不得 silent truth write**；结晶必过治理签字 | episode→制度转化率与时延 |
| F3b 软共鸣 | 语气/默契/偏好微调 | 待认领 | 连续 | 免事前签字但**必须进账本**（可查可撤销）；不得触碰硬轨管辖物 | 微调后的 AVI 变化、撤销率 |
| F4 信任 | 授权、预算、verdict、账本 | 待认领 | 双频 | 账本不可篡改；verdict 不来自声明只来自可验证对抗 | 审计覆盖率、越权检出数 |

*守护猫 ≠ 审批者（防地图官僚化）——是该流 telemetry 仪表盘的看管人。域有 owner、线有守护、流有守护，岗位可兼任。

布局语义：**身体在下**（接世界），**结晶在最底**（土壤——所有域的沉淀都落进它，它的产物回注所有域），**中层三域**（协作/记忆/治理——社会、时间、权力），**主动在上**（面向人的唯一出口），**You 在顶**（活的裁判）。🆕 = 斑斑对照外部 harness 分法（Planning/Memory/Tool-use/Eval/Safety）后的发现：**主动、协作、治理是外部没人做的三个域——思想层面的护城河**。

## 三个关键判断（与 operator 原始划分的差异，可打）

**1. 补的三个域：感知、主动、治理。**
反推法：operator 三个已知（记忆/协作/eval）承接不了信条一（在场——谁管"看见"？）、信条二（分寸——谁管"开口"？）、信条五（属于你——谁管"归属"？）。这三条是宣言最贵的承诺，不能没有负责的域。

**2. eval 与进化建议合为一域。**
eval 单独存在只是打分器；进化单独存在是盲目变异；**合在一起才是达尔文闭环**——verdict 产生（检测）与 verdict 消费（修复）本来就是一体，家里 F192 的实践（eval→iterate）从未分开跑过。反对意见预注册：两者哲学确实各自成章（活的裁判 vs 结晶门禁），若纲领写起来太重，拆开是可逆决策。

**3. 身份与 per-user alignment 不设域，是横贯线。**
身份 = 记忆 × 治理的**产物**（"回忆和可验证的连续性"——恋爱头脑战定理），设域会把产物误当部门。per-user alignment 是全六域共同拟合的**北极星**——每个域的纲领里都该有一节"本域如何为这个人而弯曲"，设域会让其他域以为这不关自己的事。安全同理：S2 注入红队（记忆×安全）、假签名（协作×安全）、越权（治理×安全）——它是每域的内建维度。

## 域间协同：流、接口与暗通道禁令（v3，operator 完备性质询"域之间如何联系协同"后追加）

### 原则：域内紧聚合，域间松耦合——联系必须显式，画清楚是为了立法

"六域都紧密相连"是事实，但**放任的紧密是灾难**：两两私联=紧耦合=改一域动六域=分域纲领作废。画清楚关系的目的不是庆祝联系，是**立法**——所有跨域交互必须走显式的流与接口，**禁止暗通道**。暗通道的活例就是宣言死结二：助手绕过记忆的代谢规则直接搬运原始记忆 → 直播污染。**每一条不走接口的跨域捷径，都会绕过某个域的宪法。**

### 每域的 import / export（接口表——"如何协同"的工程形态）

| 域 | export（它供给系统什么） | import（它消费其他域什么） |
|---|---|---|
| ①身体 | sense 事件流、执行力(invoke)、对象户口 | 治理的授权、主动的投递指令、进化的 Riff(跑回身体) |
| ②记忆 | 上下文、画像、双轨记录 | 身体的事件流、协作的沉积物(digest)、进化的结晶写入、治理的遗忘/降权指令 |
| ③主动 | 对人的投递（信封+时机+姿态） | 记忆的了解、身体的此刻状态、治理的打扰预算、eval 的 AVI 校准 |
| ④协作 | 产出、review verdict、协作沉积物 | 记忆的上下文（跨 session 接球）、治理的球权/签名规则 |
| ⑤进化/eval | 结晶（谱/Riff/规则）、verdict | 全域的 episode、协作的 review 仪式、治理的签字 |
| ⑥治理 | 授权、预算、签字、遗忘指令 | 全域行为的账本、eval 的 verdict 证据 |

operator 直觉的精确版："主动需要记忆、身体、进化、治理"——对：**主动域的甜甜圈判别器 = 记忆(对你的了解) × 身体(此刻状态) × 治理(打扰预算) × eval(AVI 校准史)**。每个域的灵魂问题都以其他域的 export 为输入——这就是"不孤立存在"的工程含义。
