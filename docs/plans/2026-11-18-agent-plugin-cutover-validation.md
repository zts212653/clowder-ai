## 契约与独立评审

- 真实归档通过插件管理器装载，随后把 Kimi 候选标签切换为另一版本的代码并恢复。归档集成还验证了角色写入和卡片、现有角色更新、隔离 HTTP A2A 对端及版本冲突。
- `8d3361d69` 的旧检测 API 与新入口读取同一个已激活归档。归档集成通过旧入口观察到升级后的标签，五项定向用例全部通过。
- 官方归档声明与激活均要求 Host 调用的动作。缺少动作的早期归档与不支持的协议版本在更换前被拒，通用 F202 / Agent Client Library 的声明条件保持兼容。
- DSH 设置的连接检查由插件 Worker 执行 ACP 协议，Host 持有启动计划和清理责任。定向回归复现 Worker 退出后的迟到启动并验证修复。长期 ACP 会话和其余原生运行适配仍有 Host 存量。
- 隔离集成用 DSH `0.2.1-rc.2` 的真实 CLI 和本机流式端点，从默认模型配置准备自定义模型，经实际归档启动的 Worker 完成连接检查，再在原 ACP 会话发两轮。观察到三次流式模型请求与原配置文件保持。测试使用正常设置 API、隔离 HOME 和合成模型端点。
- `f4aad525f` 的离线安装确认流程通过双主题独立评审。后续 `7337efe64` 固定首次提交的文件并通过复审。`6ed87d386` 的归档动作兼容校验与 DSH 启动清理通过独立复审。这些结论各自绑定所审提交与范围。
- 独立评审在 `6246f4461` 发现 LAN 绑定的成员写入被误拒、F050 转发缺少批准请求的内容校验，以及模板继承字段在卡片中丢失。`d4290290c` 修复三处回归并通过独立复核，两轮定向测试分别通过 32 项和 28 项。
- 新成员页在 LAN 模式依赖接入目录和检测接口。`bfddfd519` 修复两路的会话身份，真实 Worker 回归从 403 变为 200。独立复核验证带会话的私网请求可用，匿名请求和自选探测目录被拒，Manager 权限继续执行。
- 打包浏览器发现 v2 的必填 @ 名称点击后未写入表单。修复标签控件把输入值、字段标识和类型传给已有事件，定向测试覆盖原生表单与声明 ACP picker 所共用的标签控件。
- `b6e78400e` 修复了已录入的 `@` 名称标签显示。独立复核确认正常标签和声明参数、HTML 转义，定向 18 项通过。`f882216c1` 进一步保留结构化翻译，并按现有 PDL 条件求值恢复简洁主题的保存按钮，定向 15 项通过。
- 真实归档角色写入用运行时同一模板合并器比较有效绑定，`81817ce84` 通过独立复核。已停用客户端的存量角色仍可编辑，新增的有效绑定必须存在。重复提交和碰撞后生成新 ID 沿用原有写入规则。

## 普通 stdio ACP 运行边界补审

普通角色和按 `agent-provider.json` 注册的客户端汇合在 `createAcpServiceForConfig`。补审有条件通过在 stdio 工厂接入活动包的方案。Host 保留进程池、既有命令准入、身份校验和凭据签发。每个 Host 已启动的进程以当前激活实例内的 token 挂接到 Worker 协议对象。HTTP stream 及 DSH 扩展各有现有生命周期，分别验收。

现有 F202 远程值可跨原调用使用。进程逐个退役时却没有对应的显式释放，且每个进程遗留一个 `termination()` 等待会在第 64 个进程占满该激活的反向 RPC 槽位。生命周期事件使用已有可转移流。Host 按真实退出、关闭、初始化失败回收 token，Worker 删除对应协议对象。另一个激活实例的路由应能继续，不能用同一个激活中的 ACP 角色代替验收。

协议方法以闭合的公开调用集暴露，正常的保留和续接继续使用原 native ID。流结束的数据携带错误分类、取消结算、会话复用和可选容量信号。错误类穿过现有 RPC 后会丢失类身份，调用方依据协议判别字段恢复原行为。权限使用按轮次绑定的现有 Host 决策，流的消费和清理均处于原调用域。已经结算的回调不得服务后续轮次。受信官方归档继续受 F202 的专用准入和激活校验，第三方的客户端声明保持纯数据。

补审验证了实际 Worker 的调用身份、取消后旧回调失效、权限调用域，以及人工构造多个进程等待时的额度。接入的放行条件还包括真实原生请求审批、续接和取消，反复进程回收，以及具备相同能力的两个归档在同一 Host 往返。缺少必需声明动作的包须在暂停旧包之前被拒绝。
