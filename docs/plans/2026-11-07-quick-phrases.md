# 快捷用语

跟踪 [Issue #1898](https://github.com/zts212653/clowder-ai/issues/1898)。

## User Journey

范围为当前用户在不同会话中手动保存和复用的用语。安装并启用插件后，点击聊天输入框工具栏的书签图标。输入框有文字时，确认保存当前文字。输入框无文字时，浏览每页五条的列表，输入即可筛选，选中一条后继续编辑草稿。每条用语末尾可请求删除，确认后刷新当前页。图片和附件在各步骤中保留。

## 实现边界

Architecture cell: `thread-chat-surface`、`plugin`

Map delta: none

Host 持有当前草稿、确认交互和焦点。插件通过已有的声明式 UI 注册和 HTTP 转发提供列表和写入，沿用当前用户会话和启用代次校验。只有确认保存后才发送文字给已启用的快捷用语插件。插件持有按用户隔离的用语存储。

## 验证

- Host 的组件测试验证停用时隐藏入口、选用后回填及保存确认。路由测试验证入口只出现在指定区域。
- 插件测试验证每页五条、搜索结果、删除后页码回退和用户隔离。
- 在桌面与窄屏的聊天输入框验证同一旅程。使用本地归档验证安装、启停和再次启用后用语仍可读取。
