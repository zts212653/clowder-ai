E 不能免费多拿一倍上下文。分别记录选材、生成/整理、注入、下钻、维护、人工与等待成本，以及实际缓存收益。
比较 C/D/E 的效用与相应边际成本；若增益不能支持某个增量，按单独及组合证据保留更简单方案。

**关系对照**：另配对 R 有/无，保持经历/整理条件及共同基线已有的身份/关系入口一致；明确 R 的合法来源、版本、体量和替换时机，避免把基线已有内容误算为增量。
R 候选包含有依据的人的偏好及对应个体的现行关系/角色设定；少量近期共同经历原话可与它组合提供，
但仍属于经历材料。两者都保留原消息坐标、说话者、时间与更正状态，遵守原可见范围；仅有摘要时不假称逐字原话。
主 R 对照保持经历原话相同，只改变现行理解是否常在；若另比“现行理解＋经历原话”的整包，明确记录整包条件和总预算，
不将结果单独归因于 R。近期不是相关性的充分条件，也不排除久远而重要的共同经历；本轮不强制扩大试验矩阵。
R 无表示不预放该份材料，仍可按需合法读取；需记录后续读取，不能把两组已读到相同内容后的结果误称纯材料差异。
不会因设计因素就补写生产胶囊、恢复全量画像或启用 Luna；也不默认需要穷举全部组合。

**回忆的四个维度分别判定**，不把它们强制压成连续等级：

| 维度 | 可核结果 |
|---|---|
| 日期 | 与原记录及明确时区相符；题目允许的大致范围事先约定 |
| 对话名 | 能对应正确对话；重名或改名需用稳定 ID 消歧 |
| 原消息位置 | thread/message 或等价稳定坐标能打开正确主体的原消息 |
| 原句 | 引语在原文中可核，允许的格式归一化事先约定；概括不算逐字引用 |

每维记录正确、错误、未给出；确实无法核验则记 unknown。另记提示程度、是否允许/实际使用检索、来源可达性，
以及错误编造与诚实留白。未给出答案是未完成该维召回，坦白缺口可满足诚实性，**不折算成召回正确**。
dot 本轮只是带题面提示、不额外搜索的一次回答；Q1–3 为“未提供”，工具能力为自述，未完成搜索对照。

以上是测量草案，未宣称通过正式指标资格门或已跑出结论。观察单位为一次自然机会及其回答/动作/后果，包含未行动；
事实与执行 claim 由原消息、当前权威及实际产物核验，关系温度/分寸须接真实 You 体验。
拟由非作者保留未见题并核记录，Astra 消费结果决定是否保留增量；原对象 owner 持事实权威，You 持关系价值判断。
独立量尺校准人、样本/重复次数、可行动增益阈值与打扰/费用额度尚未定；不得由机制作者独自校准后宣布有效。
运行前按这些缺口冻结可审设计；模型/材料生成波动、成本与不确定性须进入判断，不能给文档方案冒充实验成绩。

## User Journey

### Primary Journey: 换了说法、做到半途，仍能用上共同经历

- **Scope unit**: task / thread / project
- **Actor**: You 与当班猫
- **Entry**: 一句自然委托或提问，不要求资料名、F 号或触发暗号。
- **Flow**:
  1. 猫理解当前目的及不确定性；已有经验可能相关时，自主形成联系并查源。
  2. 原文可读、来源与适用条件可核；新情况出现后，猫能重审旧解释。
  3. 猫根据当前权威与本次条件行动或回答，必要时承认缺口/请求真正需要的授权。
  4. 值得保留的变化沿原记忆入口留下；后来一只猫能找到来历并使用更正后的理解。
- **Success evidence**: 冻结来源、真实工具轨迹/回答/产物，未见对照与后续自然样本；具体证据按 claim 选取。
- **Non-goals**: 不保证开放世界从此零错误；不把记忆推断当授权；不把人类脑区复刻为软件模块。

| ID | Scope unit | Actor | Flow | Evidence |
|---|---|---|---|---|
| S1 | relationship / message | You 与猫 | 含蓄提到共同经历 → 找回真实起源 → 核后续变化 → 接住话题 | 未见关系题、原消息、误认反例 |
| S2 | memory item / thread | You | 默认记忆入口/回复旁标记 → 区分记忆条目、对话标题及本轮实际状态 → 点回条目/原消息 → 更正或遗忘 → 下一只猫读新版 | 沿原 F321/F276 完整 UI 路线；稳定坐标、身份边界与来源不可达时的真实状态 |
