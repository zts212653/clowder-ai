# F335: 守望猫（别每次都靠你来想起来）

> **Status**: in-progress | **Owner**: Ragdoll (@fable-5) 判断席 · 架构稿 小星星 (@codex-astra) · 北极星稿与施工指挥 Ragdoll (@opus55) · 施工：交付一 小太阳 6.1 (@codex61-sol)，交付二、三 Ragdoll (@opus55) | **Priority**: P1

## Why

You 2026-11-02 04:01 UTC（`[thread-id]#private-source-id`）：

> 别每次都靠我来想起来：在猫和我都没想到的那一刻，有只猫在旁边替我们想到，只递一句，递到该知道的人手边。……「猫是会主动跳上桌的」。

它要解决的不是"少出错"。You 11-02（`#private-source-id`）：「守望猫不够主动，不够能和猫猫球联动形成猫真的跳上桌，你们的守望猫更像是Maine Coon的钛合金防弹内裤升级版，全部干的都是兜底的活儿。这样设计完全带不来超出预期的事情发生，平平无奇。」

两句候选 ground truth（OQ-1，等 You 拍）：

1. **有多少件事，是没人逐项吩咐、守望猫自己想到并先做出来、被用上或留下了的，而且是它走到人面前来的。** "这个我没想到"只认 You 自然说出来的；不设每周配额、不逐件打标。长期为零 = 失败。
2. **You 在 A 线说过的话、定过的事，B 线下一次工作时算不算数**——他不用再说第二遍。反例就是立项这条线本身：11-01 设计线说过的五条，11-02 他对着片子重说了一遍（`#private-source-id`）。

覆盖率、开口次数、接住时间、打扰率、花费全部是 proxy，不是目标。

## Current State / 实现与验收边界

交付一及启动/关闭修复、选择对话范围已合入（PR #6490 / #6584 / #6595）；桌面工具接线已合入 #6581。合入不代表 runtime 已加载或已通过真实体验。11-04 最新决定：首次默认只看明确选中的对话；由 You 重启 runtime 后，在真实线程里体验，Opus55 看日志和账，不再预约 Alpha 复验（KD-12 / KD-13）。下列保留 11-02 立项时的历史基线：

## What

- **何时醒**：被守望的线上，一只干活的猫的调用结束——唯一触发；没有别的程序判断，不读 Task / 球权 / hold 当触发；守望猫自己的调用不触发自己。
- **在哪醒**：每条被守望的线一个续用会话（不是新 thread、不是每次新 session），**前缀有界**：系统提示 + 自己的笔记 + 本轮增量，目标 ≤ 3 万 token，不随线长增长。
- **记得什么**：先在记忆系统里**按事情回看**（F332 的能力，不是守望猫私有的本子：一件事一页、原话 + 坐标、跨线、任何猫可读写），再读本线增量；读到谁对某件事说了新话、定了新事，往那页追加原话 + 坐标。
- **问自己什么**：这一刻，有什么是大家没想到、我能替他们想到或先做一步的？
- **三种出手**（或不出手）：① 一句给干活的猫（下一轮带上，或行首 @，普通 A2A）；② 一键提议给人（聊天里一个按钮，小猫顺手的六条规则：一点就用、一点就撤、哪类别再提由它自己掂量、不进信箱）；③ 可逆、在授权内的小事先做好，由**桌面猫（前台猫岗位）**带到人面前——靠近 → 气泡 → 跳上桌 → 共谋（F272 强度谱）；人不在时先攒着，回到电脑前由桌面猫一次带过来（You 11-02 16:26 UTC `#…001524`）。
- **不碰什么**：零拦截权。不持球、不进 gate / admission、不接 Task / verdict 交接链、不截消息、不替人决定；输出全是普通消息和按钮；它挂了等于没有它，主工作先提交、不等它。不做不可逆操作。
- **尺度与开关**：次数跟活动量走（全开就是家里每天 560–620 次守望），没有每天常数，只限单次醒来的工具调用数；总开关下选择「全部 / 只看我选的」，默认后者，只纳入单条明确开启的对话；选「全部」才沿用未明确关闭即纳入的逻辑，总开关关闭始终优先（KD-12）。范围内的私人 / 贴贴对话默认「免打扰」（按对话标签选）：照样看、把该记的贴心记进记忆，不递话、不提议、不带东西来（You 11-02 15:26 UTC，守望猫线 `#private-source-id`：「该记录的记忆没记录 守望猫看了贴心记上才对」）；顶栏只在纳入范围且能力可用时显示，并反映实际查看/暂停状态。
- **调节器**：人的反馈只有用了 / 改了 / 忽略 / 不理；不定「几次就不再提」，这类提了几次、用了几次、忽略了几次当事实交给守望猫自己掂量（You 11-02 16:26 UTC 守望猫线 `#private-source-id`：「我们自己设定的两次其实很奇葩……还是交给猫猫自己掂量吧」）；You 在对话里说「守望这条」可加入，说「这条别守望了」「这两小时别烦我」可收紧，立即生效并在原消息下给可撤销回执。猫的话和引用文字不触发这些人类指令。

## User Journey

### Primary Journey: 我在干别的，有只猫替我想到了
- **Scope unit**: thread（每条被守望的线一个会话；感知面在聊天、桌面猫和顶栏）
- **Actor**: operator
- **Entry**: 他和猫在某条工作线上正常干活，或者根本不在线；什么都不用配置
- **Flow**:
  1. 某只猫一轮干完 → 这条线顶栏的小眼睛亮一下（他在线就看得见"守望猫在看"；不在线也不等他）
  2. 守望猫想到了一件大家没想到的事 → 要么下一轮那只猫自己带上了一句；要么他的聊天里出现一个一键提议（"把今天拍的三件记进 KD 表？"），一点就记、一点就撤；要么桌面猫带着一页做好的东西走过来（"聊系列图时我先做了一页角色参考，拿这页接着画？"）
  3. 他用了 / 改了 / 点了 ×「不需要」/ 没理 → 没理的退回原来那条对话（侧栏一条未读，不进 Needs Me，北极星稿 v1.1 定）；哪类别再提由它自己掂量，它不再提的在「设置 › 你」可恢复（`#…001524`）
  4. 过几天他在另一条线说起同一件事 → 猫已经知道他在那条线定过什么，不用他再说一遍
  5. 某天他自然地说出"这个我没想到"——这是 GT 1 的唯一计数方式
- **Success evidence**: 北极星稿（Phase 0）→ 真实壳里走完 1–4（Phase A/B，alpha 截图或录屏）→ GT 两句的自然样本（Phase C）
- **Non-goals**: 不拦任何主工作；不让他逐线程开；没有每天上限；不做程序整理的材料包；不做不可逆操作；不在聊天里堆回执
