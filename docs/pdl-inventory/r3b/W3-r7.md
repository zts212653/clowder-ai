## 2. 看得见的变化

- **设置 → 系统 → 通知**：浏览器推送只有一个开关；不可用时显示实际 permission/worker 状态。诊断打开 `dialog.push`，展示服务配置、订阅目标与最近投递事实，按当前状态给出订阅、取消、测试、生成、保存动作。生成后显示待保存，保存拒绝保留密钥草稿与错误。
- **对话菜单 → 对话设置 → 目标**：多个 nativeTargets 时出现成员选择。保存或重试同步作用于所选成员及打开设置的那条对话。
- **对话设置 → 思考强度 / 速度**：每个成员独立一行，选项来自各自 owner；空选项恢复继承。不同成员支持的选项不再被压成固定三档或共同 speed。
- **对话设置 → 运行时**：能力与权限两行显示真实值；任一对应观测不可用时显示该原因和 warn tone。不会显示写死的“能力可用”或 workspace write。
- **接上已有会话**：已绑定但没有可见 boundThread 的行没有“打开”；有可见来源的行打开对应对话，已绑定行不能再次作为导入选择。

上述交互通过原样引擎、组件和 PDL 的 JSDOM 测试验证，没有启动应用或浏览器服务；本轮未做真实设备推送投递。
