- **内置星球**：把项目 `pdl-app/starry.js` 的 `pdlRegister({id:'builtin.starry', entries, frames, views, ops})` 声明移到 `theme/default/layout.js`（或主题对应的 frame 声明文件）；entry `starry.title` 用主题现有方式 `tc('settingsUi.starry')`，view 内的 frame title 保持 `t:` 声明。复制后项目删掉该声明块，仅保留 `VM.starryFrame`、`A.starryFrameMessage` 和平台 frame 生命周期绑定。
- **主题色点**：`theme/default/palettes.js` 的 `PDL_SYS_THEMES`：`sys:1` 补 `accent:'#b05f45'`，`sys:2` 补 `accent:'#3b6ea8'`，与同文件各自 palette 数据一致；`theme.themes` 无需应用侧配色查找。
- **生命周期标签**：`theme/default/views-settings.js` 的 `LIFE_NODE.label`、stage label 和 group caption：按 raw `name` 映射七个枚举 `session-start/session-init/turn-build/client-invoke/turn-close/session-close/hook-events`。在 `i18n/{zh,en}/settings.json` 增加对应标签和说明；建议中文依次为“会话创建 / 会话初始化 / 回合构建 / 客户端调用 / 回合结束 / 会话封存 / Hook 事件”。当前副作用是空格已有原始 id，不会显示空 pill，但中文仍待复制。

- **作品分页**：`library/blocks.js` 的 list、`library/widgets.js` 的 cards 需要同一个通用的近末尾继续读取出口；相应 schema 声明跟随，`theme/default/views-ws-items.js` 的 `WORKS_BLOCKS` 为平铺 / 分组 / cards 绑定它。声明明确后，应用才停止 `usePagedGlobalWorks` 自动耗尽 cursor，提供下一页来源。滚动回不到标题仍待现场定位；没有声称某个 CSS 改动已能解决。
- **时间**：`library/ui.js` 的 `FORMATS` 增加上述按日历日切换的通用格式（沿用 `fmtParts` / owner 时区）；`theme/default/views-chat.js` 的 `navThreads.rename.time`、`CHAT_HEAD.time/receivedAt`、`chat.node/sys.time` 和消息刻度时间绑定选用它；`thread.row` 在 `theme/default/views-cafe.js` 的时间列也选同格式，覆盖搜索 / 整理列表。
