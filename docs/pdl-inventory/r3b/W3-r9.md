### 前后流向

之前：`VM → chatModels → chatPort.models → ProjectDataBinding.models → binding.models`，读取时重新组织业务数据，依赖 r3b29 的每次渲染缓存。

现在：`hook 原始回执变化 → ProjectDataBinding.data → 既有 PdlAppHost publish → receiveChatData / receiveProjectData → chatDataSnapshot.project[owner] → 应用 VM`。接收端复用线程 / sidebar 的比较、复制规则，以记录 id 比较列表 / 记录表，保留未变项引用，返回 added / changed / removed / orderChanged / fields。相同 push 不修改持有的 project 引用、不渲染；局部 push 保留其他 owner。VM 读取不返回宿主取数。

UI 输入（筛选、选择、草稿、语音输入选择、进化阅读位置）沿既有 state 引用传递，不混入回执比较。四个原来通过抛错交给公共边界的读取（desktop / general / sources / trash），改在接收回执时发布原有 dataError / dataOk；带 load/error 的其他 owner 继续由已有错误 / 重试组件呈现。
