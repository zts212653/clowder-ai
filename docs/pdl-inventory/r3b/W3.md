# W3：第四轮旧 React 界面清理

基线 `a35307a2da`，分支 `feat/pdl-migration-w3`，复制版本 `design-accepted-r135`。前三轮已由协调者提交、合并（W3 合并 `3669fadfa5`）；前三轮记录从历史提交查看。本轮只清理旧 React 界面及其测试，README 进度表只读。

删除 **2,225 个文件**：旧源码 / 样式 **1,160**（其中含 JSX 的文件 808、CSS 19）、测试套件 **871**、测试夹具 **194**。另裁剪 37 个混合模块的旧 JSX，保留 116 个已有函数 / 类型 / 常量声明；13 个既有 Next 页面保留入口与 metadata / redirect 等导出，页面体改为 `null`。全量 Vitest 失败由 **253 降到 59**，剩余 59 条均在删前已失败，没有新增失败。

## 1. 按层改动

- **引擎（通用机制）**：未改。
- **组件库**：未改。删除的是项目中的旧 React 界面，不是原型 library。
- **主题数据（PDL）**：未改。`public/pdl/**`、`public/pdl-app/**` 全部无 diff。
- **应用（VM、动作）**：`src/pdl/**` 全部无 diff；现用 hooks、stores、API 客户端、socket、类型和平台桥沿原引用保留。只删除旧 React 模块、旧页面体和对应测试；混合模块按声明裁剪，没有移动、重命名或重新实现逻辑。
- **后端**：`packages/api` 无 diff，没有删接口。旧调用方与当前调用方见 [接口清单](W3-r4-api.md)。
- **测试入口 / 既有规则范围**：`packages/web/package.json` 去掉已删除的测试参数和失去测试目标的 authored-duck probe。默认 test 的 unit / smoke / guards 阶段仍保留，smoke 保留 navigation-continuity。原 border 规则只移除 39 个已删除文件对应的 45 条 scope 记录；已无适用文件的 card 测试随之移除，divider 测试改用仍在原 scope 内的 ConsolePanel。正则、错误条件和余下文件的规则不变。没有加规则、检查、依赖或跳过标记。

## 2. 导入图证据与删除方法

### 真实宿主入口

`src/app/layout.tsx` → `components/AppShell.tsx` → `pdl/PdlAppHost.tsx` / `ProjectDataBinding.tsx` → 当前 bindings、hooks、stores、API / socket / 平台桥。

`AppShell` 的实现是 `() => <PdlAppHost />`，不使用传入的 `children`；旧 `(chat)/layout.tsx` → ChatContainer 等子页面树没有挂载位置。本轮删除旧 chat layout，保留 `/`、`/thread/[threadId]`、settings / memory / signals / mission-hub 等 URL 的 Next 页面登记、metadata 和 redirect。

### 图的构造与边界

1. 用 `git ls-files packages/web` 枚举受版本控制的代码 / CSS / JSON，以实际 web tsconfig 的 alias 和 bundler module resolution 交给 TypeScript AST / `ts.resolveModuleName`。记录 import、re-export、import type、import-equals / require、字面量 dynamic import、相对 `new URL` 和 CSS `@import`；类型边也按依赖保留。排除 public 复制文件和 `*.local.*`。
2. 以全部 44 个 PDL 非测试模块、文档 layout 为入口求闭包；另显式保留 Next backend route.ts、worker、d.ts、构建脚本 / mock setup、layout 静态 stylesheet 的源 CSS。四组独立页面暂按保留入口处理，原因见第 5 节。根脚本还读取的 `capability-tips.seed.json` 已确认保留，未因前端无 import 删除这份脚本输入。
3. TypeScript checker 按实际引用声明区分“只导入类型 / helper”与“调用 JSX 组件”。例如 ChatInput 留下 draft 类型和原 draft re-export，IndexStatus 留下 parser / types，成员表单留下 MemberText / MemberChoice 等类型，插件配置留下原 decoder / validator。对 37 个混合模块作 AST 比较，**116 个保留声明的结构变化为 0**；移除了 80 个旧 UI / 私有配套声明。
4. 只删除在宿主及保留入口闭包之外、属于旧界面树或其配套消费者的源码。测试除 import 图外，也记录 readFile / Vite build input / dev route 的静态路径；旧 AppShell classic / v2 画面契约随旧 shell 删除。混合测试只去掉旧组件部分，保留 history、Socket、ACP input、API body / CSRF、command registry、export selection 等真实数据断言。F190 混合套件从 167 条裁到 19 条，保留尚有消费者的组件 / token 检查。
5. 再扫 packages / scripts 对被删 web 模块的静态 import：**0**。外部脚本的字符串定位器另列清单，不把历史检查 / 截图定位器当成产品挂载入口，也不伪造替代 JSX。

本次的一次性分析脚本在 `/private/tmp/pdl-w3-r4-{graph,symbols,extended,retained-bodies,external-audit,api-audit}.cjs`，没有加入 CI。入口闭包和导入边作为数据留在仓库供复核，没有新增“防再犯”检查。

## 5. 保留、不确定与需要协调的项

### 独立产品入口：本轮保留

`/story/[storyId]`、`/story-export`（含 grep-hippocampus）、`/starry`、`/collective` 的页面和完整依赖树保留。这些页面仍登记在 Next，回放 / 导出、星空 / Present Loop、共建作品等功能的边界没有由本轮任务明确迁走；后端还把 Present Loop 配置位置指向 `/starry`。当前 AppShell 丢弃 children 是已存在的迁移状态，本轮不据此自行删除这些独立功能，也不更改宿主去重新挂载。

典型保留链是 `app/collective/page.tsx → CollectiveLaunchSurface → CollectiveDocumentWorkspace → F307ExperienceWorkbench → owner renderers`，因此 ApprovalItemCard、ArtifactsPanel、WorkspaceHomeV2 / HomeWorksSummary、CardBlock、视频控件等不能仅因目录名或测试失败就删。保留见证 TSV 逐项列出上游。40 条关联失败继续暴露，需要协调者确认这些独立入口退役 / 迁移的范围后再清理，不为 v2 主题保留 React。

另外有 **25 个**未找到运行入口见证的通用导出 / 类型 / 样式 / 测试辅助模块，以及 **53 个**没有充分旧 UI 静态依赖证据的浏览器套件，详列 [不确定清单](W3-r4-uncertain.tsv)。这轮不凭名称删除。layout 显式加载的 CSS 与 vendor stylesheet 输入完整保留，避免改变现用 PDL 的外围样式。

### 外部检查 / 历史证据定位器：没有静默改成通过

根 scripts 中仍有已删旧 UI 文件 / browser journey 的字符串定位记录，已列 [外部引用清单](W3-r4-external-references.tsv)。它们不是前端挂载消费者；除了确认仍被脚本读取而保留的 capability-tips seed，本轮没有将根工具或 feature claim 一并重设计。

需要协调者审的明确例子：`docs/design-gate-claims/f307-phase-a-real-shell.json` 仍指向已退役的 F307 browser journey，`scripts/design-gate/claim-journey-paths.test.mjs` 会校验它存在；`public-brand-validation.mjs` 的固定产品源码表仍提到 SplitPaneView / ChatContainerHeader / ThreadIndicator；F269 overflow ledger 仍有旧组件定位器。它们若继续跑旧契约，需要退役条目或由新 PDL journey 重新提供证据。本轮未动根 feature claim，也没有运行或声称根全量 gate 通过。

### 后端接口与既有宿主失败

接口清单共有 373 条方法 / 路径记录，209 条在当前静态扫描范围未找到调用；还有动态方式 / 只见路径的记录，明确标为待核实。正典头像 GET / POST / upload、成员会话策略恢复继承、目录 bootstrap-check 等均保留后端。清单只是审阅依据，不是无人使用证明，更没有自动删接口。
