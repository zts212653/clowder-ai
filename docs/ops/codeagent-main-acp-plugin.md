# 在现有 main 架构中接入 CodeAgent

本改动直接基于公共 `main@4ef8e7404a0f17a5750fdaba974f229647300281`，不依赖角色重构分支。它补齐 Host 通用能力；CodeAgent 插件负责声明工具，企业机器负责安装程序、认证和实际模型连接。

## 用户操作

1. 在现有设置的插件入口安装 CodeAgent 插件并启用。验证所用包是插件仓 PR #166 的 `clowder-ai-codeagent-0.1.0-beta.2.tgz`，SHA-256 为 `83c3a06bb2a1d9501a4fea34bd82a4adf562f75bd9143635f5392c16ecbddf9e`。插件和 Host 分别交付，不自动下载、安装企业程序。
2. 在该插件的配置中，通常保留默认命令 `codeagent`、启动参数 `--acp`。程序不在 Host 的 PATH 时，填入 Host 机器上的可执行文件绝对路径；每行一个参数。远程浏览器本机上的路径不能代替 Host 路径。保存后多个成员共用这一连接，不需要分别创建三个 client。
3. 按企业客户端要求配置其认证；不在插件表单中粘贴凭据。需要 bypass 时可使用用户已确认的参数 `--acp`、`--permission-mode`、`bypassPermission`、`--allow-dangerously-skip-permissions`，每行一个。此参数方式不需要插件新增环境变量传递能力。是否批准 ACP 权限请求是单独的权限选项，不能从 bypass 参数推导；新可配置固定客户端默认拒绝未处理的权限请求。
4. Windows 引导目录留空时沿用当前 Host 选择策略；确需指定时选择 Host 本机已有可用父路径，在表单点“检查引导目录”，通过后保存。检查会创建专用目录，仍校验目录与祖先信任，不修改系统盘或既有祖先 ACL。本片不携带旧内网分支的兼容策略切换；如目标机器无法通过现有策略，须单独处理部署策略，不能把本片当作该问题已解决。
5. 在成员配置的“使用工具”选择 CodeAgent，再设置角色的名字、昵称和职责。内部工具引用保持 `plugin:official.codeagent/codeagent`；角色身份不写回插件的工具 ID。
6. 在原有模型字段选择“跟随 CodeAgent 设置”或客户端报告的具体模型。“跟随”保持成员模型覆盖为空；只在客户端实际报告默认模型时显示默认值。未报告会明确提示“默认模型尚未确认”。模型目录可读不表示认证、额度或真实 prompt 已通过。
7. 修改程序路径或参数后，在成员配置点“刷新”。配置错误时修正并重新保存即可恢复，不要求卸载或删除历史。已有角色绑定不因保存连接而迁移。

插件配置写入继续沿用既有 owner / 直接本机管理策略，不赋予内网远端浏览器新的管理权限。模型查询同样要求 owner 和既有本机访问条件；只传工具引用，Host 从已验证、启用且已注册的插件包和保存配置解析启动项。

## 模型与身份能保证什么

模型探测复用有界 ACP 子进程，只发初始化、创建会话，以及用户显式选择已报告模型时所需的配置请求，不发送 `session/prompt`，拒绝客户端文件和权限请求。但启动程序、建立客户端会话仍可能有客户端自身的磁盘或认证行为；不能将它描述成纯文件读取或完全无副作用。未报告/无法采用的模型不标成成功；刷新失败会保留可用选项供修复，但清除上次默认模型和实际采用的断言。

原生 system/persona 接口尚无 CodeAgent 文档或真实响应证据。当前 main 的通用 ACP 路径仍将系统上下文与用户任务共同发送；本次在配置入口如实说明，未伪造私有字段、未宣称原生身份适配完成。未来取得客户端协议后，应在 client 映射处补原生身份入口并分别验证首轮、续聊、恢复和压缩。仅靠静态插件声明不足以证明身份质量。

## 作者验证与现场验收

作者已在隔离项目中用实际 tgz 和生产 Manager 跑通安装、配置、双角色独立会话、续聊、权限拒绝/显式允许、错误配置恢复、停用/启用及重建后配置回读。ACP 对端为明确标识的协议 fixture；测试不调用真实 CodeAgent 或模型，不冒充企业认证、MCP 工具执行或 A2A 质量验收。

浏览器验证使用当前工作树的生产表单组件与 API、隔离 owner 身份；覆盖未知默认、保存参数、刷新、显式模型选择与页面重开。未将该组件预览当作整套 Settings 登录/导航验收。临时服务采证后停止，数据留在任务 artifacts 中，不触碰用户原生 HOME、认证、会话、Redis/SQLite 或 ACL。

企业机器后续验收：按上述步骤安装配置；发送真实任务检查所用模型、权限和错误提示；续聊并重启 Host 回读同一角色绑定及历史；单独验证 Clowder MCP/A2A 调用。原生身份在取得明确协议前仍是待验证项。离线预置、内网插件源和内网更新源均不属于本片。
