# Code as Harness：同一件事，You 说了第二遍之后

## 为什么有这个技能

被纠正之后，顺手的做法是道歉、记一条、再加一条规矩。家里的账本说这样不够：

- 共享主仓本地提交，同一个坑踩了八次，每次只多写一段规则，做法长到八步还是挡不住。最后是一个发布脚本加一个钩子解决的（*(internal reference removed)*）。
- 规矩和关卡加多了也翻车：能自己定的事推回给人，删了能找回的也不敢删（同目录 `2026-10-26-humphrey-ball-kicking-inventory.md`）。

所以这一页只管一件事：You 不得不把一件事说第二遍时，查清它为什么没到位，改到他不用再说。

## 先把被纠正的事做完

诊断不抢手上的活。十分钟内修得动的当场修。修不动的另开线程，手上的活照做。

## 第一问：这件事，家里之前有没有

搜了再答，不凭印象。「又」「怎么还」是口头语，不是证据。算「有」的是：之前真发生过同一件事，或者家里已经有一条写着该怎么做的东西（规矩、记忆、文档、他的原话）。

- **没有**：这是新知识，不是错题。关于他本人和咱们的关系，`cat_cafe_remember` 选 profile；关于什么算好，选 taste；别的照做就行。到此为止，不往下走。
- **有**：是错题，往下走。
- **只是工具或流程坏了，没让他重说**：留爪感差，不入本。怎么报见同目录 `paw-feel.md`。

## 入本

在错题本记一行：*(internal reference removed)*。记哪七样、状态怎么走，那一页写着，这里不重复。

有两件事那一页替不了你：

- **当轮记。**「当时眼前有什么」只能趁热写，那一轮的提示词和记忆投影事后取不回来。头三条错题都是事后查的，三条都缺这一份，有一条到现在分不了类。
- **大翻车另写长案例**，放翻车档案的 `cases/`，错题本挂一行指过去。

## 第二问：该用上的东西，当时在不在眼前

这一问决定往哪修。别跳过它直接「再记一条」。

| 断在哪 | 往哪修 |
|---|---|
| 在眼前，没用对（当轮就有，或者取回来了） | 它已经在了，再加一条没有用。先查三种可能：东西太多太碎把它盖住了；一份旧文档被当成了硬前提；这只猫在这件事上需要更多辅助。主因家里还没查清，不要先下结论，拿下一次真实交付来检验。 |
| 不在眼前，因为没存下来 | 存到下次会经过的地方，而且是全家读得到的地方。只有自己读得到的本子不算存下来（错题本 M004）。 |
| 不在眼前，因为工具坏了或没取回 | 修工具，留爪感差。 |
| 不在眼前，因为没人点名所以没想起 | 把它挂到一个本来就会发生的动作上：合入、开工位、接手、发布。靠猫自己想起来去读的东西，几乎没人读（*(internal reference removed)*）。 |
| 分不清 | 写明缺哪份记录。先补记录，不猜。 |

## 修的时候

- **修法按问题选。** 确定的程序错误用代码修；多余的前提和关卡直接撤；判断失误拿实际交付检验。加一道关卡也有成本，它会拦住正事。
- **程序只做机械的事**：把料送到眼前，拦住一个确定错的动作，替猫跑重复的步骤。程序不替猫判断，不用关键词、if else、过滤去猜意思。这是 You 定的边界。
- **同类顺手扫一遍。** 被纠正的这一类问题，手上的活里还有没有。有就一并修，不扩成全仓重构。
- **超出自己领域的**，找对口的猫或先调研，不硬编方案。
- **修复照常走审查**，不自己诊断完自己合入。

## 收尾

- 在错题本那一行写上退役条件：一句看得见的行为。退役和抽查怎么走，那一页写着。
- 回 You 一句话，带上错题本那一行的编号：断在哪，改了什么，什么算好了。不发诊断卡。

## 另开修复线程时

开场消息要自包含：问题、证据坐标、断在哪、要的结果，并写明加载本技能。新线程里没有「上面的讨论」。

## 常见错误

| 错误 | 后果 | 改成 |
|---|---|---|
| 听到「又」就开始诊断 | You 随口一句话换来一份报告 | 先搜，家里之前没有就是新知识 |
| 被纠正后道歉，再写一条规矩 | 同一个坑踩八次 | 走第二问，按断点修 |
| 东西明明在眼前，还是「再记一条」 | 眼前更挤，下次照旧 | 这一类不加规矩 |
| 为了修它放下手上的活 | You 还在等原来那件事 | 先做完，或另开线程 |
| 事后才补「当时眼前有什么」 | 查不清，分不了类 | 当轮记 |

## 和别的技能

- `debugging`：第一次出现的程序错误。
- `receive-review`：审查的猫提的意见。
- `incident-response`：已经造成不可逆损失的事故。
- `paw-feel-daily`：每天分拣全家的爪感差。它派出去的修复线程用本技能。
- `writing-skills`：同一类新活做到第二次、想沉淀成技能时用。一次性的新活直接做。
