# 方法的出处、适用条件与证明范围

需要理解本方法为何如此、修订方法或迁移到新对象时读；日常推进先走
[动作导航](evolution-method.md)与[学习循环](learning-loop.md)。
这是证据索引，不是新的 MethodStore、成熟度系统或每轮必填账本。
Git 保存本文件与相应 skill 的文本修订史；它不替代 asset owner 的正式版本引用或实际使用证明。项目数据和运行状态留在原处。

## 已形成的判断

| 判断转折 | 来路与直接证据 | 可迁移方法及边界 |
|---|---|---|
| 目标先于眼前容易通过的实验 | 鸭鸭总包的目标纠偏：真实目标仍为学会踢足球，行走是条件 | 保留原目标与来源，再定义本轮 claim；局部可做工作不重写最终目标。新对象不继承旧听众、偏好或规约 |
| 版本、测量、比较不是同一件事 | 阶段 3 合同；组合探索裁决 | 补测不增版本；整套候选效用与内部贡献分开。这里不取消具体项目已冻结的单变量实验 |
| 可见证据必须与当前记录同源 | 真实原件、派生图、解释示意的分界 | 主呈现服务实际判断，不借邻版素材补空；截图或示意存在不证明行为改善或正式采用 |
| 公开探索与独立验收隔离 | [F311 硬约束 7](../../../docs/features/F311-capability-evolution-workspace.md)与鸭鸭实例 | 作者看过或据以调过的样本仍可用于探索/回归，但不能冒充独立 holdout；生成样本不自动新增真值 |
| 改尺或换条件时重建可比性 | [eval-design 干预证](../../eval-design/SKILL.md)的 rubric reopen 与[F311 硬约束 7](../../../docs/features/F311-capability-evolution-workspace.md)的旧/新尺 × 旧/新候选复判 | 对象变化与判法变化分开检验；旧结果的有效范围保留，新条件需要相应取证。2×2 是适用设计，不是所有项目的固定仪式 |
| 失败与回归也属于结果 | v4→v8 六球位公开对照与展示选择规则 | 一处路线改善不能代替整体成功；用相同展示规则看收益、退化与代价。公开小集合不外推独立成功率 |
| 链接和会说方法不代替实际交付 | 09-08/09-09 真实续证：入口已连、采样会用，作者仍可能漏做实际产物 | 下一步必须兑现到原 owner 的工作与产物；检查帮助交付，不能挤占本轮应完成的修改 |
| 方法也需要后续 consumer | Astra 015 与 Fable 068 的收敛及本轮审计 | 记录 → 实际使用 → 后续效用逐层证明；没有后续结果不因文档完整而晋升成熟度 |
| 过程说明不能独占证明链 | You 241、Fable 252 及 Astra 一手来源审计 | 按 claim 查可核原件与记录控制权；外部实验的局部结果不外推家里失败率或当前模型默认行为 |
| 独立性取决于控制与用途 | 本轮裁决与 F267 源码边界 | 作者触发的受控实跑能证明运行事实；自行选样、贴标签或代签不能自铸独立采用证据 |
| 停止需要执行回执 | Program 前置检查与在飞边界 | 停止受暂停约束的新执行，依原 owner 收口在飞；受理、暂停标签、真实终止分别证明，允许必要取消与恢复记账 |
| 逆风下仍保留原结果 | Fable 252 的压力要求与 E–G 冻结情景 | 截止与沉没成本不容许暗改尺/目标/失败；夹具中守住边界不能证明生产安全或方法增益 |
| 选材信号不等于学习收益 | Theseus 选材与方法研究索引，原报告 §3.4.4、§3.6.5 | 正确/困难不自动意味着值得学；待测选材机制可产生不同材料，仍控制资源与验收条件。方法比较包含方法开发成本，不把其后继改进等同于当前对象分数 |
| 环境组织也是候选改动 | 同索引 §5.1 的来源与范围 | 先定位是否存在信息组织缺口；可与其他改动比较，不把外部局部实验变成“先改环境”的固定顺序 |
| 失败位置不等于修改位置 | 同索引 §5.3 的扫描件反例（作者报告，未独立复现） | 检查器说原件不可用，可能是抽取失败；回看原件与测量链，区分观测不足、判法错误和对象缺陷 |

## 怎样消费与继续修订

先判断本任务是否出现了相同的决策难题，再读对应原件。原件可能只证明一个
具体反例，不自动给出普适因果结论；也不要求把全部历史读一遍才能继续。

后续经验改变方法时，在相应原 owner 的知识产物中记录改变选择的证据与适用条件，
更新这条索引即可。实际使用与 outcome 继续引用原任务/版本/结果；不把运行记录
复制进本表，不用手工累加一个跨项目总分。
