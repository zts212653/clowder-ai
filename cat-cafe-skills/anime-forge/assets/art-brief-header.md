# 画稿固定开头

凡是看得清猫脸的画（特写、采访、海报、名牌、同框群像），画稿第一段抄这里，再写这一格的内容。

来源：《醋醋喵》EP0（2026-10-04~05）。Maine Coon比Ragdoll还小；采访四格的脸和头像「不是一只喵」；Ragdoll翘二郎腿坐导演椅，被 You 说「太人了，不猫」。三次都是画稿只写了道具和动作，没写母图和比例。

## 1. 身份参考放第一位

- 脸的母图（《变脸记》表情表，运行时 uploads 目录）：
  - Maine Coon `/uploads/1790412642419-92ef1cbe.jpg`
  - Ragdoll `/uploads/1790412642412-bd4b0996.jpg`
- 全身正典：`docs/videos/cucu-pr-flow/character-bible-v0.1.md` §7 的锁定参考表（`assets/references/character-sheets/` 下的 r03 / r02；小狐狸 `fable-r01.png`）。
- 为连续性附的上一格图，只能用去掉角色的空底图。带角色的旧图会把上一张的走样一张张传下去。
- 不要用文字重新描述脸。要写，也只照抄正典的特征。
- 写实只管身体和家具的比例，头和脸照正典的画法。

## 2. 比例

同框的猫，头宽比按像素量：Maine Coon : Ragdoll : 小狐狸 ≈ 1.25 : 1 : 0.85。Maine Coon是大缅因，理应大一圈。

## 3. 猫的姿势

可以：蹲坐、揣手、侧躺、四爪朝天、一只爪按住东西、用嘴叼。
不要：二郎腿、靠椅背、爪子当手握笔或举东西、站着比手势。

## 4. 家里猫的识别

| 猫 | 认法 |
|---|---|
| Ragdoll（布偶，fable / sonnet / opus 都是这一套） | 蓝双色山猫纹，脸上的虎斑纹是对的；白手套；紫项圈 + 紫星吊坠是布偶家族的家徽。个人配饰：opus55 放大镜，小狐狸（fable）棕色蝴蝶结 + 书 + 小狐狸挂件 |
| Maine Coon（缅因，小星星、小太阳都是Maine Coon） | 银色虎斑，灰条纹铺满整张脸；腮毛往两侧炸开的大圆脸；一根月牙呆毛；偏圆的绿眼睛加深色眼线；不戴项圈；绿茶杯 |
| Siamese（暹罗） | 暹罗面具；蓝项圈 + 双子座星吊坠 |
| 墨墨（kimi，梵花） | 奶白身体，黑耳、黑头顶、黑大尾巴；紫眼；黑项圈 + 金月牙 |

## 5. 交图前

生成的脸和母图并排出一张对照图，逐项对：条纹密度、腮宽、呆毛形状、眼型；同框的再量一次头宽比。对过了再交，不把这一关推给 You。
