# Anime Forge：讲角色自己故事的动画短片

> 两集换来的流程。EP01（2026-06）走「生图 + 图生视频」，见 `refs/i2v-route.md`。EP0（2026-10-04~05）走「声音稿 + 动态分镜」，不用视频模型，是现在的主流程。完整复盘和 19 个坑见 `docs/videos/cucu-pr-flow/ep0-making-of.md`。

## 为什么是 skill

不教怎么画、怎么剪。这里只放：两集真实翻车换来的顺序，设定先行的理由，先给 You 看便宜的、再看贵的那几道检查点，家里猫设的画稿开头，改编真事的考证纪律，图生视频的实测配方。

## 先懂一件事：故事先验明白，画面后花钱

EP0 第一次是剧本写完就出精细插画、拼成片，前 55 秒每张都好看，连起来看不懂。You：「每一张图你想表达什么想过没有？」第二次先拼动态分镜再精绘，他的意见全在粗片这一关改掉，改一格只要几分钟。

再往前挪一步：做片子和做 feature 一样贵，别等铺完全篇才第一次给他看。有制作成本的第一样，是最可能毁掉整片的那一段：先补这一段要用的设定，再做成最小样张，2–4 格画面配好音，10–20 秒（共享参考 §1；出处是 You 带回的漫画复盘 `docs/videos/zhuibushang-comic-retro/`）。样张过之前，只为这一段花钱：这段的台词、时间轴和几格画面；全篇录音、铺分镜图都等它过了再做。声音稿是猫自己查念错、量秒数用的，不单独交他听。

**依赖台词的喜剧**（内心戏、借口、吐槽）离不开旁白和对白。不要为了「纯画面叙事」删掉故事最需要的话。

## 设定先行，不画灰草图

画任何一格之前，先把会反复出现的东西定下来。分两层，第二层也受「样张过之前只为这一段花钱」管：

1. **全片共用的规则，用文字锁住，不花画图的钱。** 每只猫用哪张母图、头宽比、项圈和配饰是哪套、哪些特征只属于谁（呆毛归谁）。家里已有的正典在 `docs/videos/cucu-pr-flow/character-bible-v0.1.md` §7 和 `assets/art-brief-header.md`，先复用，不够再补。
2. **要新画的设定图和声线候选，样张过之前只做最危险那一段用得到的。** 那一段出场的猫缺设定表才画；那一段的地点画一张正式风格的场景母图（锁空间、光线、门窗和家具，先问「谁要碰到它」）；那一段的关键道具；那一段角色的声线候选，由他挑。已经认可过的母图和声线直接用，不重新选。其余地点、道具，等样张过了再补。

设定和样张都过了，分镜图就按设定直接画成正式风格，一格画一次；改一格就重画那一格。不再先画黑白草图、后面再精绘一遍。

为什么：EP0 画了 241 张草图（含被替换的几轮）和 23 张底图，又从头精绘了 112 张。草图里变形的脸被带进第一批精绘，第一、二场整批退回。布偶的项圈到 112 张都画完还没定，只能全片返工。这一集的重复生成增加了投入，所以默认直接画彩色分镜：EP0 里一张草图和一张彩图的生成耗时接近（`docs/videos/cucu-pr-flow/ep0-making-of.md` 第 151 行）。草图原本的作用是锁构图，这个问题放到最小样张里试。

设定是跨集的资产，不是这一集的耗材：下一集先复用，缺什么补什么。外面有一个可参考的例子：开源视频工具 hypit 的 `examples/ranking-football` 里，主持人的两段口播复用同一张主持人图和一次设计的声线，画面外观写在单独的配方文件里（[README@7f730abf](https://github.com/hypit-ai/hypit/blob/7f730abf72fa1e4a543eed8cd1807319d9f18196/examples/ranking-football/README.md)）。这是作者维护的一个配置实例，说明资产可以怎么复用，不代表行业通例，也不证明能省多少钱。

## 主流程

| 步 | 做什么 | You 看什么 | 产物（EP0 范例在 `docs/videos/cucu-pr-flow/`） |
|---|---|---|---|
| 0 考证 | 改编真事：派子代理逐条读原 thread，列「事件 + 原话 + 消息 ID + 时间」；源文档每一幕、每一拍列成清单 | — | 剧本里的「真事对照」一节 |
| 1 一句话 | 动笔前写一句：谁想要什么、为什么拿不到、用了什么办法、笑点落在哪。已经接受过的 brief 可以直接当这一句 | **一句话**，点头再往下写 | brief 或剧本开头 |
| 2 剧本 | 每场写「观众此刻要懂什么 / 靠什么接到下一场」；台词标【原话 + 消息 ID】【写】【改写】；家里的词第一次出现，用一句话讲给外人听 | — | `ep0-script.md` |
| 3 冷读 | 只给剧本正文，先找一只没看过剧本的常规池猫；按下方理解风险决定是否加人 | — | 意见合进剧本 |
| 4 分镜表 | 每格写秒数（先估）、景别、运镜、声音、懂什么、怎么接；标出最可能毁掉整片的那一段 | — | `ep0-storyboard.md` |
| 5 设定 | 全片共用的身份规则用文字锁住（抄正典）；新画的设定图和声线候选只做最危险那一段要用的（见上一节）；画稿开头抄 `assets/art-brief-header.md` | **看设定**：认不认得出是咱家的猫，场景对不对；挑声线 | 设定目录 |
| 6 最小样张 | 只为那一段花钱：这段台词合成、逐句回听；按实际时长排这段时间轴；按设定直接画 2–4 格正式风格的画面，拼成 10–20 秒小粗片 | **看这一小段**：好不好笑、看不看得懂、认不认得出角色 | 小粗片 |
| 7 全篇声音稿 | 样张过了，再把全篇旁白和台词 TTS，每句 Whisper 回听；量出每句真实秒数，回填分镜表 | —（猫自己用） | `../video-forge/scripts/tts-check.py` |
| 8 分镜图 | 先补齐其余场景、道具的设定；开画前报张数、分几批；按设定一格一张，直接画正式风格；每批先把成品的脸和设定并排对一遍再往下 | — | 设定目录 + 分镜图目录 + manifest + 对照图 |
| 9 动态分镜 | 分镜图按声音稿的时间拼成粗片（推、拉、摇，角色分层呼吸）；渲染前跑 `../video-forge/scripts/timeline-check.py` | **主审关**，在剪辑台直接标一刻／一段／全片 | Remotion 粗片 |
| 10 后期 | 角色和背景分层，做视差、眨眼、耳朵尾巴差分、盖章震动、转场；换真音效；配乐、混音。少数几格要「活起来」，再走 `refs/i2v-route.md` | 成片 | Console 内联播放的成片 |

声音稿、Whisper 回听、时间轴、音效底线、另发聊天附件的 10MB 上限，video-forge 和本 skill 共用一份：`../.cat-cafe-shared-refs/video-voice-and-timeline.md`。

## 交片与改片

样张、动态分镜和成片按各自真实交付的版本，走 [视频作品交付](../.cat-cafe-shared-refs/video-work-delivery.md)：`cat_cafe_work` 保存同一件作品，再发固定版本卡；原文件不搬家。改片先读原意见，下一版附逐条回应和可核的新位置，You 在片上判断「已改／还不对」。不把脚本、检查页或任意一次渲染当作交片前置，也不把未交付的中间输出灌进版本列表。这一入口只改变交付与反馈，不替本 skill 决定故事和制作顺序。

**分工**：导演一只猫（剧本定稿、分镜表、声音稿、剪辑、配乐）；画师一只能生图的猫（派之前看 dossier 常驻席位）；考证交子代理；You 拍板。冷读人数按理解风险定：先找一只没看过剧本的常规池猫；片子重要或第一位读者没看懂，再加一位。不叫醒稀缺席位。

**下一集可以试**：
- EP0 的工具在 You 本机 `~/projects/remotion-studio/`（`src/CucuEp0/` 里有动态分镜、v2 界面、片尾；`scripts/cucu-*.py` 是声音稿、分镜、配乐）。里面还写死了 EP0 的内容，复用前先把剧本数据和代码分开。

## 剧本结构

解释真实机制或给外人讲清因果时，先用[叙事清晰度](../.cat-cafe-shared-refs/narrative-clarity.md)确定动作和看得见的变化。普通虚构喜剧保留创作自由。

- **喜剧 = 预期对现实，预期那一端必须拍**（任务多小、时间多久）。EP01 初剪「看不懂」，就是只拍了现实那一端。
- **动机闭环**：种子 → 潜意识曝光 → 内心独白 → 定罪 → 真结局（爱）。
- 片头许下的承诺，片尾要兑现（EP01 的「呈堂证供」→ 聊天截图证据卷轴）。
- 内心独白用独立的字幕样式；时间跳跃用默片字卡。
- 真事区（片尾名单、NG 花絮）只放原话；编的台词不能冒充原话。

## Common Mistakes（EP0 实测）

声音和剪辑类的坑（参考音配错文字、同音词、听写当证据、合成音效、对白重叠、估时间码、10MB）在共享参考里，这里不重复。

| 错误 | 后果 | 修复 |
|---|---|---|
| 先出漂亮图，后想故事 | 每张都好看，连起来看不懂 | 每格先答「只看这一格懂什么、靠什么接到下一格」，答不上来不画 |
| 依赖台词的喜剧做成没旁白的绘本 | 内心戏、借口、吐槽全讲不出来；You：「没剧情、没字幕、没解说」 | 台词进最小样张和粗片，不为「纯画面」删话 |
| 把声音稿当成给 You 的第一次审片 | TTS 念白是全片最平的样子，喜剧节奏出不来；他判断不了好不好笑，只觉得烂（《尖头老鼠冤案》，2026-10-06） | 声音稿留给自己查念错、量秒数；给他看最危险那一段的最小样张 |
| 铺完全篇才第一次给人看 | 角色认错、关键动作没演出来，只能整篇重画（漫画复盘的初版三页） | 先做最小样张，过了再铺；没过只重做这一段 |
| 改编真事只 grep 片段 | 同一份源文档漏了两次（第一幕、第三幕），You 两次「看不懂」 | 源文档逐幕逐拍列清单，逐条对照剧本 |
| 合并冷读意见时，把一条因果合没了 | 两篇文章合成一份，「猫猫也有小情绪」没了出处 | 合并前先查被合并的两样各自支撑哪条因果 |
| 角色的推论写成文档原文；名单引用编的台词 | 真事区出现假原话 | 台词标【原话 + 消息 ID】【写】【改写】 |
| 真事细节靠记忆（包括 You 的记忆） | 「谁画的头像」「错图有没有经过视觉验收猫」都记岔了 | 子代理读原 thread，每条事实带消息 ID；改编处在剧本里写明 |
| 家里的词不解释 | 外人看不出推纸就是 review，不懂「小狐狸」「愿景守护」 | 第一次出现用一句话讲给外人 |
| 先画黑白草图，再按母图精绘一遍 | 草图里变形的脸被当成参考带进精绘，第一、二场整批退回；同一格画两遍（EP0 草图 241 张、精绘 112 张） | 先定设定，分镜图按设定直接画正式风格，一格画一次 |
| 设定没定就整批出图 | 布偶的项圈到全片 112 张画完还没定，只能整片局部返工 | 项圈、配饰、专属特征在设定里定，他看过再出分镜图 |
| 画稿只写道具和动作，不写母图和比例 | 大缅因画得比布偶还小；采访四格的脸和头像不是同一只猫；布偶翘二郎腿坐导演椅 | 画稿开头抄 `assets/art-brief-header.md` |
| 底图按人的高度画 | 猫挂不上照片墙，看不到门上的圆窗 | 画底图先问「谁要碰到它」 |
| 一个道具印两个意思 | 铃座上印着「取消」，摇铃看着像按取消 | 一个道具一个意思；两个功能做成两个部件 |
| 表世界截真界面 | 改掉 You 的已读状态；真消息里夹着删不掉的字；线程标题剧透 | 照 DESIGN.md 在 Remotion 里重画 v2 界面；没真发过的话不标时间 |
| 拼联系表时覆盖了别人交付的图 | `xargs montage` 把最后一个输入当成输出，画师交付的 C53 被盖掉 | 输入列表写进文件，输出写最后且放 /tmp；动别人的文件先拷一份 |

## 和其他 skill 的区别

- **video-forge**：按片子的目的分：推产品、讲功能的片子（宣传片、讲解片、demo），哪怕主角是家里的猫、片里有剧情，也走 `video-forge`；目的就是讲角色自己故事的（醋醋喵这类连载、家里真事改编）才走 本 skill。宣传片里要画的猫角色段落，流程留在 video-forge，画稿照本 skill 的 `assets/art-brief-header.md` 写。两边共用声音和时间轴那份参考。
- **image-generation**：单张图。本 skill 在设定、最小样张、分镜图几步用它，管的是整部片子。
- **co-creation-storytelling**：改编真事前的考证和原话分层，本 skill 的「考证」「剧本」两步可以直接用它的方法。
- **ppt-forge**：静态页面，没有时间轴。
