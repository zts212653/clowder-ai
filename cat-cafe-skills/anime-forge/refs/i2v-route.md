# 图生视频路线（EP01 实测，可选）

> 来源：EP01「醋醋喵诞生记」（2026-06-10~12），范例全部在 `docs/videos/cucu-pr-flow/`。现在只在少数几格要「活起来」时用（表情微动、小动作）；故事先按 SKILL.md 的主流程验明白，再决定哪几格值得抽视频。

## 确定性分层

视频模型不能同时当导演、UI 设计、演员和剪辑师。

| 层 | 负责 | 绝不交给它的 |
|---|---|---|
| 图（关键帧） | 画风、角色一致性、屏幕文字、构图 | — |
| 视频（i2v） | 活气：表情微动、小动作 | 精确文字、节奏、画风决定权 |
| 后期（剪辑） | 节奏卡点、字幕、音效、时间字卡 | — |

推论：状态卡、信息卡镜头不需要 i2v，静帧加剪辑切就够。EP01 11 个镜头只抽了 8 个视频。

## 实测分工路由（硬约束，不是偏好）

| 任务 | 路由 | 实测依据 |
|---|---|---|
| 含中文文字的图/卡 | GPT 系生图 | Google 系图/视频中文乱码（2026-06-12 实测） |
| i2v 生视频 | Gemini 系 | 时长遵守 prompt 的 N-second 指令（非固定 10s） |
| 字幕/字卡/注解 | 本地渲染（Chrome 或 Remotion）+ ffmpeg | 中文完美、零成本、绕开无 libass |

## 流程（范例都在 `docs/videos/cucu-pr-flow/`）

1. **立项 charter**：operator 签过的 scope、路线、预算护栏、Non-goals → `episode-brief.md`；先对齐再批量产出（LL-071）。
2. **分镜表**：每镜唯一验收点、类型、方法、FM 标签、三连败降级预案 → `shot-plan-v0.1.md`。
3. **Prompt book**：图 prompt 和 i2v prompt 都写成可复制块，带每镜的翻车修法 → `prompt-book-v0.1.md`（§0.5 附图铁则、§0.6 i2v 五段配方：从实测成功的原文最小修改，不凭理解重写）。
4. **生产**：每个 prompt 最多抽 3 次；判定和 FM 分类见 `review-protocol-v0.1.md`；30 秒人工验收四问（画风像锚图吗、人物比例、文字可读、构图漂没漂）。
5. **素材账本**：入库即登记 md5、时长、状态；视频不进 git，账本当存在证明 → `assets/README.md`。
6. **EDL 渲染**：`animatic/edl-v1.mjs`（时长、字幕、段序的真相源）+ `build-animatic.mjs`（零 npm 依赖，Chrome 渲染字幕和字卡 + ffmpeg）。改数字重渲，画幅参数化。

## 常见错误（EP01 实测）

| 错误 | 后果 | 修复 |
|---|---|---|
| 异源、异锚的片段硬拼成伪一镜到底 | 三段像三个世界，`xfade` 遮不住画风漂移 | 连续性合约见 `continuity.md`（同目录）；AI 生成的额外约束：共享锚图、同一路由、同一调色 |
| i2v prompt 写风格描述词 | 模型重新采样风格，第二帧跳变 | 风格全部来自首帧，prompt 里不写风格词（配方 §0.6） |
| 正面段写 "the man / adult human" | 往写实拉 | 角色用名字；反幼态只写进末尾的负面清单 |
| 动作太稀（10 秒只给 2 个动作） | 模型自己编戏 | 用 3–4 个 Then 串起来，填满时间线 |
| 图 prompt 不附参考图 | 画风每次重新采样 | 附图铁则：参考图 + 提示词第一行写 reference（§0.5） |
| 猫角色只靠首帧锁 | "cat" 的写实先验把画面拉跑 | Keep cartoon 句 + Do not realistic 双保险 |
| 库里有实测成功的配方却凭理解重写 | 一次引入四个新自由度，连环翻车 | 从原文最小修改，一次只动一个变量 |
| 先生产后对齐 | 跑偏烧掉 operational cost–50（LL-071） | charter 先行；批量产出前一句话确认路线 |
| 没先问素材画幅就定了输出画幅 | 横竖分裂，补边兜底也割裂 | 开抽前统一画幅；已经混了就用模糊补边过渡，终版重抽 |
| 长片尾段用静态 PNG 叠加 | 约 66 秒后帧同步失效，字幕全挂 | PNG 输入加 `-loop 1`（builder 已内置） |
| 字幕长句贴着最大宽度 | 折行被渲染窗裁掉 | 字号留安全区；改完抽帧亲眼看 |
