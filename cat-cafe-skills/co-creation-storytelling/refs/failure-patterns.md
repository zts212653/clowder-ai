# 真实失败怎样变成叙事方法

以下模式来自一次新员工大会成长故事的多轮共创。这里保留方法，具体人物信息与完整素材留在原项目，迁到外部项目时不复制。

| 当时的诱惑 / 失败 | 为什么会失真 | 这次采用的动作 |
|---|---|---|
| 套新员工四格漫画 | 受众是新员工，被误画成主角当年刚入职 | 先建立时间账；格数与年份分离 |
| 把“临时高层演示”画成满是高管的会议室 | 猫写的戏剧化复盘被当作事件记录 | 当事人订正为远程会议；场景事实与叙事气氛分开 |
| 罗列名校、奖项比例 | 可见材料被误当作都应公开 | 只保留故事需要且确认公开的粒度 |
| 把多年日常画成平线 | 把没有职级跃迁误当作没有积累 | 用框架建设与根的生长保留分量，不编新高潮 |
| “我不想再传话了” | 缺了传什么、给谁、为何需要人 | 画四个通用 AI 窗口与经过人手的方案/代码 |
| “模型更换，积累保存” | 书架能表示保存，不能解释方法如何形成 | 加入定标准、看执行过程、比较改动效果的动作 |
| 团队成立收尾，或只加“能力继续长” | 组织节点吃掉猫侧成长，未来只剩愿望 | 为持续托付与能力改进各画完整旅程，标明探索中 |
| 低保真写全就算成图讲全 | 生成可能改箭头、漏动作、放错台词 | 按最终图片核对贡献与过程；区域+角色+台词定位修图 |
